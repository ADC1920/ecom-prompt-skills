# 电商生图提示词 SOP 全库

本技能是 34 篇电商生图提示词 SOP 的原文库，按「用户需求 → 路由 → 读对应文档 → 按文档执行」工作。所有提示词和步骤都在 references/ 的原文里，本文件只做路由，不复制提示词内容。

## 使用流程

1. 从用户消息识别三要素：**品类**（服饰/美妆/美食/3C/家具/包包/海产/杯壶/檀木…）、**产物**（主图/详情页/买家秀/SKU 图/模特图/视频）、**动作**（生成/反推/翻新/替换/翻译/批量）。
2. **第一判据（先于路由表）**：请求是「裸主图方案」或「裸详情页方案」——没有任何品类专项命中，不涉及反推/翻新/复刻/SKU 批量/比例转换/图内文字翻译/买家秀/场景图/模特换装/视频，也未点名本库 SOP——则**不进路由表**：主图方案转 `ecom-main-image-prompts` 技能，详情页方案转 `ecom-detail-page-prompts` 技能。其余情形继续第 3 步。
3. 在下方路由表定位**唯一最匹配**的 SOP 文档。裁决顺序：用户点名篇号 > 品类专项 > 通用篇；用户点名篇号（如「02 号 SOP」「爆款反推里的 04」）按路由表文件名前缀匹配（篇号与目录号 01-05 重合时，以用户描述的内容意图为准，拿不准先问）；两篇都可能匹配时按路由表中的判据列裁决，仍拿不准就先问用户，不要凭感觉挑。
4. 用 Read 读取该文档全文（路径相对本技能目录，路由表已给出完整路径）。
5. 严格按文档的步骤和提示词执行：文档里写给外部生图工具（Gemini/即梦/可灵）的提示词，原样输出给用户或按用户产品信息填充后输出；文档里的硬规则（产品外观锁定、信息真实性、不露脸等）不得删减或弱化。
6. 文档未覆盖的边缘品类，选最接近的品类专项或通用篇，并向用户说明选择依据。

## 与既有技能的分工

裸主图/裸详情页的通用方案由 `ecom-main-image-prompts`、`ecom-detail-page-prompts` 承接（见使用流程第 2 步第一判据）。本技能的价值在**原文与细分场景**：品类专项规则、爆款反推、SKU 批量、图翻译、模特与视频等，以及用户点名要 SOP 原文时。

## 硬规则

- **忠实原文**：SOP 里的提示词是调校过的成品，引用时保持规则条款完整，不做「精简版」「合并版」；确需按用户产品定制填充，只替换占位内容，不动规则。
- **示例值必须替换**：SOP 示例里已填死的具体值（目标语言、平台名、品牌名、张数、比例等）一律按用户需求替换后再输出；拿不准某个值是示例还是固定要求，先问用户。
- **不过度发挥**：文档没写的平台规则、参数、价格、认证不得编造；文档明确说「不能确认就保守表达」的，照做。
- **一次只路由一篇**：不要同时读多篇同类 SOP 拼接输出；用户要主图+详情页两样时，可各读对应篇但分开交付。
- 文档内互相引用的编号（如「见第 X 步」）以被读文档自身为准。
