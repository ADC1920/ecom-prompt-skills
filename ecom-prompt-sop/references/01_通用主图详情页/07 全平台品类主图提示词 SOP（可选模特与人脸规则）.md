# 07 全平台品类主图提示词 SOP（可选模特与人脸规则）

## 适用目标

这份 SOP 用于把 `1 张产品实拍图` 或 `多张同一产品不同角度图`，生成一整套适配全平台的品类主图 / 轮播图 / 商品图生图提示词。

适用平台包括：

1. 国内货架电商：淘宝、天猫、京东、拼多多、1688、得物。
2. 内容电商：抖音小店、快手小店、小红书店铺、视频号小店。
3. 跨境电商：Amazon、Walmart、eBay、Etsy、TikTok Shop、AliExpress、Shopee、Lazada、Temu。
4. 品牌自营：Shopify、独立站、品牌官网商城、私域商城。

这份 SOP 的重点不是输出固定 6 张或 8 张主图，也不是套“首图、卖点、场景、细节、规格、收口”的固定模块，而是让 AI 根据产品特性、平台规则、类目审核风险、可见信息、购买决策链路和用户输入，自行规划最合适的主图数量、主图顺序、图片职责、构图方式、模特使用方式和图中文字策略。

唯一固定的是输出格式，不固定图片模块。

## 核心原则

1. 平台首图优先合规：如果目标平台首图要求严格，第一张默认走白底或干净背景、产品真实清晰、无水印、无违规文字、无无关道具。
2. 后续主图自由规划：主图组不固定模块，由 AI 根据产品决定是否需要场景、细节、尺寸、套装、模特、对比、包装、使用步骤、材质、信任或礼赠。
3. 产品外观锁定：所有图片都必须以用户上传产品图为唯一产品外观依据。
4. 信息真实：不得编造参数、认证、功效、销量、价格、排名、折扣、材质等级、尺寸、容量、成分、产地和质保。
5. 模特可选：用户可以选择不要模特、需要模特、自动判断。
6. 人脸可控：用户可以选择禁止人脸、允许人脸、仅首图禁止、自动判断。
7. 平台规则优先：当用户要求与平台规则冲突时，采用更保守、更可上架的方案。

## 核心定义

全平台主图分两层：

1. `平台首图 / 商品首图 / Cover Image`：搜索结果、推荐流、商城卡片、商品页第一张图，通常最影响点击，也最容易被审核规则限制。
2. `主图组 / 轮播图 / Carousel Images`：商品页后续图片，可根据产品需要展示多角度、卖点、细节、使用场景、尺寸关系、包装清单、模特使用、对比或品牌氛围。

如果用户只说“主图”，默认输出一整套 `平台首图 + 若干张主图组图片`，但数量和职责由 AI 根据产品和平台自行决定，不固定 6 张或 8 张。

## 默认值规则

如果用户没有填写，按下面逻辑执行：

1. `目标平台`：默认按淘宝 / 天猫 / 京东 / 拼多多 / 抖音 / 小红书 / Amazon / TikTok Shop / Shopee 等均较安全的全平台通用逻辑生成。
2. `目标站点 / 国家`：未填写时不强行输出本地化单位、尺码、法规文案和国家声明。
3. `输出语言`：国内平台默认中文；跨境平台默认英文；如目标市场明确为日本、韩国、法国、德国、西班牙等，可按用户指定语言输出。
4. `主图数量`：未填写时由 AI 根据产品复杂度、平台主图槽位、买家决策链和可见信息自动决定；简单产品可 4 到 5 张，复杂产品可 6 到 9 张，不为凑数量重复。
5. `主图类型`：默认输出平台首图 + 主图组；如用户只要广告主图，则按广告主图逻辑处理。
6. `主图比例`：默认 1:1 方图；服饰鞋包和内容电商可按平台选择 3:4 或 4:5；独立站和广告图可用 16:9。
7. `品牌名称`：未填写时国内用“品牌占位”，跨境用 “Brand Placeholder”，不虚构品牌。
8. `核心卖点`：未填写时只使用图片可见特征和高置信品类常识，不输出具体夸张承诺。
9. `产品参数`：未填写时只使用“待补充参数位”“待补充规格位”“Specs to be confirmed”等占位。
10. `是否需要模特`：默认自动判断；平台首图默认不加模特，主图组按品类和平台决定。
11. `是否禁止人脸`：默认是；如用户明确允许，仍只能在非严格首图且平台合规的场景图中使用普通商业 AI 模特。
12. `是否允许图中文字`：平台首图默认谨慎，严格平台首图不允许；主图组按平台和用户输入决定。
13. `禁止出现`：默认禁止水印、二维码、联系方式、侵权 Logo、虚假认证、夸大承诺、过度修图、无关道具、错误文字、乱码、误导性尺寸、买家收不到的配件。

## 模特与人脸开关

### 输入项写法

```Plain
- 是否需要模特：不需要 / 需要 / 自动判断
- 模特类型：手模 / 脚模 / 无脸半身 / 全身背影 / 普通商业模特 / 多人场景 / 不指定
- 是否禁止人脸：是 / 否 / 仅首图禁止 / 自动判断
```

### 执行逻辑

1. 如果 `是否需要模特：不需要`，所有主图都不出现人物、手、脚、身体局部和人脸。
2. 如果 `是否需要模特：自动判断`，AI 先判断产品是否需要人物帮助理解尺寸、穿戴、握持、使用动作或生活方式；不需要就不加。
3. 如果 `是否需要模特：需要` 且 `是否禁止人脸：是`，只允许手部、脚部、背影、肩部以下、下巴以下裁切、头部出画、无脸半身或局部使用动作。
4. 如果 `是否需要模特：需要` 且 `是否禁止人脸：否`，只允许在非严格首图的场景图中出现普通商业模特自然人脸；不得指定真实人物、明星、网红，不得出现儿童可识别人脸，不得性感化或擦边。
5. 如果 `是否禁止人脸：仅首图禁止`，首图严格无人物或无人脸，后续场景图按平台和品类谨慎决定。
6. 如果 `是否禁止人脸：自动判断`，默认采用更安全方案：首图无人物，主图组优先无脸模特，只有独立站、Etsy、小红书生活方式图、服饰上身图等低风险场景才允许普通模特露脸。
7. 母婴儿童用品默认不出现儿童可识别人脸。

### 禁止人脸固定约束

```Plain
人物约束：允许出现模特或人体局部，但只能是手部、脚部、背影、肩部以下、下巴以下裁切、头部出画或局部使用动作。no visible face, face fully out of frame, no eyes, no nose, no mouth, no identifiable face, no celebrity likeness。
```

### 允许人脸固定约束

```Plain
人物约束：只允许普通商业 AI 模特在平台合规的非严格首图中自然出现。不得明星脸、不得真人复刻、不得儿童可识别人脸、不得性感化姿势、不得误导身材效果，产品必须是第一视觉中心。
```

### 不需要模特固定约束

```Plain
人物约束：不出现模特、不出现人脸、不出现手部、脚部和身体局部，只展示产品、包装、场景和信息模块。
```

## 产品锁定规则

1. 每一张主图提示词都必须以“以上传产品图作为唯一产品外观参考，严格保持产品真实品类、轮廓、比例、结构、颜色、材质、包装、Logo、标签和可见细节不变”作为开头约束。
2. 产品品类、轮廓、结构、比例、颜色、材质、Logo、包装、标签、可见纹理和配件必须保持一致。
3. 不得新增原图没有的接口、按钮、纹理、图案、配件、包装、礼盒、功能结构或品牌元素。
4. 多图只作为同一产品的外观补充参考，不代表多个 SKU 或多个款式。
5. 如果角度看不清，不得编造背面、内部结构、隐藏功能和不可见配件。
6. 场景、模特、道具、光影和版式可以变化，但产品本身不能跑品。

## 信息真实性规则

1. 只能使用用户填写的信息、图片可见信息和高置信品类常识。
2. 不得编造认证、专利、销量、排名、折扣、价格、功效、成分、材料等级、容量、尺寸、适用年龄、产地和质保。
3. 国内文案不使用“最强”“第一”“永久”“100%有效”“医学级”“国家认证”“全网最低”等绝对化表达，除非用户提供真实依据。
4. 跨境文案不使用 “Best”“No.1”“100% effective”“Medical grade”“FDA approved”“Clinically proven” 等高风险表达，除非用户提供证据。
5. 未提供参数时使用占位：`待补充参数位`、`待补充规格位`、`Size info to be added`、`Specs to be confirmed`。
6. 不要使用平台名、竞品品牌名、第三方商标、认证标识或官方徽章，除非用户提供授权。
7. 食品、保健、美妆、母婴、宠物、医疗相关品类要更保守，避免功效承诺和监管风险。

## 主图数量决策

不要默认固定 6 张或 8 张。按下面逻辑自行决定：

1. 简单低信息产品：3 到 5 张。通常包含安全首图、核心识别图、细节图、场景或规格图。
2. 中等复杂产品：5 到 7 张。可加入使用场景、细节、尺寸、包装、卖点或信任信息。
3. 高客单 / 强功能 / 多部件产品：7 到 9 张。可加入结构拆解、使用步骤、套装清单、对比、规格、场景矩阵。
4. 服饰鞋包：通常需要首图、上身/上脚/上包、细节、尺码/容量、场景穿搭，但是否露脸由输入项决定。
5. B2B / 1688 / 工业工具：通常需要主体、规格、结构、材质、应用场景、包装/供货信息，模特少用。
6. 食品、美妆、母婴、宠物、医疗相关：宁可少图可信，也不要用虚构功效凑图。
7. 如果用户填写具体数量，严格按用户数量输出，但每张必须有独立价值。

## 图片职责任务库

下面是可选任务库，不是固定顺序，也不是每个产品都必须包含。

AI 需要根据产品特性和平台自行选择、改写、组合或创造更合适的图片职责。

1. 平台安全首图：白底 / 干净背景 / 产品完整清晰。
2. 点击主图：适合内容电商或非严格平台，强调第一眼识别和点击理由。
3. 多角度展示图：正面、侧面、背面、开合、组合状态。
4. 核心识别图：让买家一眼知道产品是什么。
5. 核心卖点图：用 2 到 4 个真实卖点解释购买理由。
6. 使用场景图：展示产品在真实生活、办公、户外、旅行、厨房、浴室、穿搭中的状态。
7. 模特使用图：用手部、脚部、背影、无脸半身或普通模特帮助理解使用关系。
8. 局部细节图：材质、纹理、接口、走线、五金、泵头、瓶身、扣具、开口、轮廓。
9. 尺寸比例图：尺寸、容量、佩戴比例、空间比例、握持比例。
10. 包装清单图：买家实际收到什么，不能加入没有提供的配件。
11. 套装组合图：仅在真实套装或用户提供清单时使用。
12. 使用步骤图：只适合需要操作流程的产品，不适合就不要强行输出。
13. 场景矩阵图：多场景适配，如旅行、居家、办公、户外。
14. 对比图：只有用户提供真实对比点时使用；否则改为优势总结。
15. 信任收尾图：售后、材质、包装、使用建议、保守购买理由，但不编造认证和评分。
16. 礼赠图：适合礼盒、饰品、美妆、文创、节日产品；不适合就不要强行做。
17. 品牌氛围图：适合独立站、Etsy、Shopify、小红书或品牌感较强的产品。
18. 广告点击图：适合用户明确要求广告图时使用，可比平台首图更有冲击，但仍不得误导。
19. B2B 规格图：适合 1688、工业件、工具、原材料、配件，重点展示规格、材质、批量供货、应用。

## 品类规划逻辑

### 服饰鞋包

优先判断是否需要上身 / 上脚 / 上包。可规划无脸模特、头部出画、背影、半身裁切、鞋脚局部、包袋手提肩背、面料细节、五金细节、尺码或容量说明。首图根据平台决定是白底单品、平铺、模特上身还是场景点击图。

### 美妆日化

优先强化包装质感、色彩、质地、使用场景、瓶身细节、泵头/盖体、规格占位、组合使用。模特默认手部、手腕、梳妆台、肩颈以下，谨慎露脸，避免功效夸张。

### 食品饮品

优先展示真实包装、食欲感、口感联想、冲泡/烹饪/食用状态、包装规格、场景。禁止编造产地、成分、营养、认证和健康功效。人物默认手部动作，不露脸。

### 家居家具

优先展示空间比例、使用状态、材质、结构、尺寸、搭配风格。模特用于比例参考时默认背影、手部、局部坐卧，不让人物抢产品。

### 3C 数码 / 家电

优先展示外观、接口、屏幕、操作、桌面场景、功能说明、配件清单、规格占位。模特默认手部操作或背影使用，不露脸。

### 运动户外

优先展示穿戴/握持/携带关系、户外场景、结构、耐用细节、收纳和多场景。可以用背影、脚部、手部、局部动作；允许露脸时也要让产品是主视觉。

### 母婴儿童 / 宠物

优先展示安全感、材质、圆角、使用场景、清洁、尺寸、清单。默认不出现儿童可识别人脸，可用成人手部、儿童背影、儿童手脚局部。宠物用品可出现宠物，但不要制造危险、虐待或夸张效果。

### 饰品珠宝 / 文玩礼品

优先展示材质光泽、佩戴比例、礼赠感、工艺细节、包装。模特默认手腕、手部、颈部以下、背影礼赠，耳饰避免露出可识别人脸。

### 百货工具 / 收纳清洁

优先展示使用前后状态、操作动作、结构细节、尺寸、场景、收纳效率。只在真实合理时做对比，不夸大效果。

### 工业品 / B2B / 原材料

优先展示主体标准图、规格型号占位、结构细节、材质纹理、应用场景、包装出货、批量陈列。少用模特，多用手部操作、设备场景或真实工位，不编造认证和检测结果。

```Plain
三、动态规划
不要输出固定模块。
每张图必须有独立价值和产品专属职责。

如果是母婴儿童用品，默认不出现儿童可识别人脸。

五、图中文字
如果“是否允许图中文字：否”，不生成任何文字、图标、徽章和信息卡。
如果“是否允许图中文字：是”，严格平台首图仍默认无文字；其他主图可使用简短中文、英文或目标语言卖点，但必须真实、克制、可读。

六、信息真实性
不得编造认证、专利、功效、销量、排名、价格、折扣、材料等级、尺寸、容量、成分、产地和质保。

不得使用绝对化和高风险词，除非用户提供真实依据。
```

## 常用返修提示词

### 模块太固定

```Plain
请重做整套全平台主图规划，不要套固定的首图、卖点、场景、细节、规格、收口模块。请根据当前产品品类、目标平台、可见信息、购买决策链路和用户输入，重新决定主图数量、顺序和每张图职责。每张图的职责名称必须贴合当前产品，不能换一个产品也成立。
```

### 首图不够平台安全

```Plain
请基于上一版重新生成平台安全首图。使用纯白或极浅中性背景，只展示买家实际收到的产品，产品清晰完整，颜色准确，真实阴影。删除所有违规文字、促销角标、徽章、水印、边框、无关道具、模特、人脸和买家收不到的配件。保持产品外观与上传图完全一致。
```

### 不要任何人物

```Plain
请基于上一版重新生成，删除所有人物、手部、脚部、身体局部和人脸。只保留产品、包装、场景道具和信息布局。产品必须清晰完整，符合目标平台主图风格。
```

### 信息虚构

```Plain
请删除所有无法从上传产品图或用户输入区确认的参数、认证、功效、销量、排名、价格、折扣、材料等级、尺寸、容量、成分、产地和质保。信息不足处改为“待补充参数位”“待补充规格位”“Specs to be confirmed”“Size info to be added”等占位。
```

### 产品跑品

```Plain
请基于上一版重新生成，但必须严格回到上传产品图的真实外观。保持产品品类、轮廓、比例、结构、颜色、材质、Logo、标签、包装和可见细节不变。删除新增的错误部件、错误纹理、错误配件、错误包装、错误文字和不存在的功能结构。
```

### 图中文字不适合平台

```Plain
请重新优化图中文字。严格平台首图不允许任何文字；内容电商或后续主图只保留简短、真实、可读的中文、英文或目标语言卖点，不使用夸大承诺、虚假认证、价格折扣、绝对化词和高风险词。文字必须清晰，无乱码和伪字。
```

## 验收清单

每套图生成后按下面标准验收：

1. 是否没有套固定模块，主图数量、顺序和职责是否根据当前产品和平台规划。
2. 每张图职责是否有独立价值，是否避免只换背景不换逻辑。
3. 产品是否与上传图一致，没有跑品、改色、改结构、改包装。
4. 首图是否符合目标平台：背景、文字、道具、模特、人脸、比例和安全边距是否合规。
5. 如果用户选择不需要模特，是否完全没有人物、手脚、身体局部和人脸。
6. 如果用户选择需要模特且禁止人脸，是否完全没有眼睛、鼻子、嘴、侧脸、半张脸和可识别人脸。
7. 如果用户允许人脸，是否只是普通商业模特，不像明星、真人、儿童可识别人脸或擦边图。
8. 图中文字是否符合平台和用户要求，是否真实、简短、可读。
9. 是否没有虚构参数、认证、功效、销量、排名、价格、折扣和平台徽章。
10. 场景和道具是否服务产品，没有展示买家收不到的东西造成误导。
11. 画面是否清晰专业，适合移动端浏览和目标平台上架。
