# 06 全平台品类详情页生成提示词 SOP（含模特局部不露脸）

## 适用目标

这份 SOP 用于把 `1 张产品实拍图` 或 `多张同一产品不同角度图`，生成一整套适配国内电商、内容电商、跨境电商和独立站的品类详情页生图提示词。

核心目标不是套固定模板，而是让 AI 根据产品品类、可见结构、使用场景、平台调性和购买决策链路，自动规划详情页页面数量、页面顺序、页面关键词、构图、模特使用方式、局部细节呈现方式和图内文字。

本 SOP 允许出现模特、手部、脚部、背影、半身、局部上身、产品佩戴/拿取/使用动作，但必须严格做到 `不露脸、不露可识别人脸、不生成眼鼻口等面部特征`。

## 适用平台

默认适配：

1. 国内货架电商：淘宝、天猫、京东、拼多多、1688、得物。
2. 内容电商：抖音小店、快手小店、小红书店铺、视频号小店。
3. 跨境电商：Amazon、Walmart、AliExpress、Shopee、Lazada、TikTok Shop、Wildberries、Temu。
4. 品牌自营：Shopify、独立站、品牌官网落地页、私域商城。

平台规则经常更新，最终上传前必须以目标平台后台最新审核规则为准。本 SOP 只提供通用安全生成逻辑，不替代平台审核规则。

## 平台画幅默认值

如果用户没有指定平台和比例，默认按 `移动端竖版详情页单页 3:4` 生成，每页可单独出图，后续再拼成长图。

| 平台类型                                       | 推荐生成方式        | 详情页默认画幅            | 视觉密度         |
| ------------------------------------------ | ------------- | ------------------ | ------------ |
| 淘宝 / 天猫 / 京东 / 拼多多                         | 单页竖图后拼长图      | 3:4 或 750:1000     | 中高信息密度       |
| 抖音 / 快手 / 小红书 / 视频号                        | 移动端强首屏、强场景    | 3:4 或 4:5          | 中信息密度，生活方式更强 |
| Amazon / Walmart / TikTok Shop             | 轮播图、A+、图文卖点模块 | 1:1、4:5、16:9 按模块切换 | 清晰、克制、可信     |
| Shopify / 独立站                              | 品牌落地页模块       | 4:5、3:4、16:9 混合    | 品牌感优先，信息分层   |
| Wildberries / AliExpress / Shopee / Lazada | 主图组加详情模块      | 3:4、4:5、1:1        | 强商品识别、强细节    |

## 使用前准备

推荐素材：

1. 至少 1 张主体完整、清晰、无遮挡的产品图。
2. 最好补充正面、侧面、背面、局部细节、包装、使用状态等多角度图。
3. 多张图必须是同一产品，不要混入不同 SKU、不同颜色、不同尺寸或竞品图。
4. 如果需要真实参数、功效、认证、成分、容量、材质等级、尺码、型号、价格、活动权益，必须在输入区填写，不得让 AI 凭空编造。
5. 如果希望带模特，优先准备产品真实使用方式说明，例如手持、佩戴、上身、脚踩、背负、坐卧、操作、收纳、局部涂抹等。

### 默认值规则

如果用户没有填写，按下面逻辑执行：

1. `平台`：默认按淘宝 / 天猫 / 京东 / 抖音 / 小红书 / 跨境均可复用的移动端详情页逻辑生成。
2. `输出语言`：默认中文；跨境平台可按用户指定输出英文或目标语种。
3. `详情页数量`：根据产品复杂度、品类决策链和可见信息自动决定，不固定为 6 页或 8 页。
4. `详情页比例`：默认 3:4，内容电商可自动改为 4:5，跨境 A+ 模块可使用 16:9。
5. `产品名称`：未填写时，根据图片识别保守生成品类名。
6. `品牌名称`：未填写时使用“品牌占位”，不要虚构品牌。
7. `品类`：未填写时由 AI 根据图片识别。
8. `核心卖点`：未填写时只基于图片可见特征和高置信品类常识生成，不编造具体参数。
9. `产品参数`：未填写时只能使用“待补充参数位”“待补充规格位”“以实物信息为准”等占位。
10. `目标人群`：未填写时根据品类、场景和产品气质推断。
11. `设计风格`：未填写时根据品类、价格带、材质、颜色、目标人群和平台自动选择。
12. `是否允许出现模特`：默认允许，但必须不露脸。
13. `模特呈现方式`：默认只允许手部、脚部、背影、肩部以下、下巴以下裁切、局部肢体动作、无脸半身，不允许完整正脸。
14. `是否允许局部细节`：默认允许，并优先用于材质、工艺、佩戴、握持、操作、尺寸感、触感和使用状态。
15. `禁止出现`：默认禁止露脸、可识别人脸、明星脸、儿童可识别人脸、虚假参数、夸大承诺、侵权 Logo、无关道具、乱码和错字。

## 总原则

1. 产品优先：任何模特、场景、道具和文字都必须服务产品，不得喧宾夺主。
2. 外观锁定：产品品类、轮廓、结构、比例、颜色、材质、Logo、包装和可见细节不得跑偏。
3. 不露脸硬约束：只要画面有人，必须写明脸部完全不在画面内或被构图裁掉，不得出现眼睛、鼻子、嘴、完整脸型或可识别身份。
4. 信息真实：不得编造参数、功效、认证、销量、排名、价格、检测数据、医学效果、环保等级、适用年龄等。
5. 页面差异：每页必须有独立价值，关键词、构图、信息重点、模特动作和局部细节不能重复。
6. 平台适配：淘宝京东偏信息密度，抖音小红书偏生活方式，跨境平台偏可信说明和干净图文，独立站偏品牌叙事。
7. 文字可读：图内文字必须短句化、层级化、模块化，不要长段堆字。
8. 可执行：每一页提示词都要能直接交给生图工具执行，而不是只写概念。

## 不露脸规则

### 允许的人物呈现

1. 手部拿取、握持、操作、涂抹、安装、打开、收纳。
2. 腕部、手臂、肩部、背部、腰部、腿部、脚部等局部。
3. 下巴以下裁切的半身模特，面部完全不入镜。
4. 背影、侧后方、低头但脸被帽檐或产品完全遮挡的模特。
5. 服装类可用无脸模特、头部出画、脖颈以下裁切、衣架、半身人台。
6. 鞋靴类可用脚部穿着、步态局部、裤脚与鞋面关系。
7. 包袋类可用肩背、手提、臂弯、背影，不出现脸。
8. 家居类可用手部触摸、局部坐卧、背影使用状态。
9. 3C 类可用手部操作、桌面使用、背影办公。
10. 美妆日化可用手部、手腕、锁骨以下、肩颈以下局部，默认不拍脸颊和嘴唇。

### 禁止的人物呈现

1. 禁止正脸、侧脸、半张脸、眼睛、鼻子、嘴、清晰脸部轮廓。
2. 禁止可识别身份的人像、明星脸、网红脸、真人复刻。
3. 禁止“看似遮挡但仍能识别脸”的构图。
4. 禁止用墨镜、口罩、头发遮挡来替代不露脸，除非脸部完全出画。
5. 禁止儿童可识别人脸。儿童用品默认使用产品、成人手部、背影或局部陪伴动作。
6. 禁止性感化、擦边、身体暗示或和商品无关的人体展示。

### 生图提示词里的固定负面约束

只要页面允许出现人物，每页提示词末尾都必须加入：

```Plain
人物约束：允许出现模特或人体局部，但必须 no visible face, face fully out of frame, no eyes, no nose, no mouth, no identifiable face, no celebrity likeness。只允许手部、脚部、背影、肩部以下、下巴以下裁切或局部使用动作，绝不出现可识别人脸。
```

如果该页不需要人物，写：

```Plain
人物约束：本页不出现人物和人脸，只展示产品、场景、道具和信息模块。
```

## 品类页面规划逻辑

AI 需要先识别产品属于哪类，再决定详情页结构。不要所有品类都套同一套页面。

### 服饰鞋包

推荐页面方向：

1. 第一眼风格页：版型、质感、穿搭气质。
2. 上身/上脚/上包关系页：无脸模特，头部出画或下巴以下裁切。
3. 面料/皮革/五金/走线细节页：局部放大和标注。
4. 场景穿搭页：通勤、休闲、户外、约会、旅行等。
5. 尺码/容量/结构说明页：信息卡和占位参数。
6. 购买理由收尾页：搭配价值、使用频率、质感总结。

模特方式：无脸半身、背影、手提包局部、脚部穿鞋、肩部以下上身、衣架或人台。

### 美妆日化

推荐页面方向：

1. 品牌质感首屏页：包装、色彩、材质氛围。
2. 使用场景页：梳妆台、浴室、旅行包、洗护空间。
3. 质地/香氛/泡沫/色感页：产品膏体、液体、喷雾、泡沫细节。
4. 包装细节页：瓶身、泵头、盖体、标签、礼盒。
5. 成分/功效占位页：仅使用真实信息或占位，不编造。
6. 使用步骤/组合搭配页：手部或手腕局部，不露脸。

模特方式：手部、手腕、肩颈以下局部、背影梳妆，不拍正脸和唇眼鼻。

### 食品饮品

推荐页面方向：

1. 食欲首屏页：真实产品、包装和食材氛围。
2. 口感/风味页：切面、蒸汽、酱汁、颗粒、冲泡状态。
3. 场景页：早餐、下午茶、办公室、露营、家庭餐桌。
4. 包装规格页：单包、整箱、礼盒、便携方式。
5. 原料/工艺/产地占位页：未提供资料时只写占位。
6. 安心收尾页：储存、食用方式、适用场景。

模特方式：手部拿取、倒入、冲泡、夹取，不出现脸。

### 家居家具

推荐页面方向：

1. 空间首屏页：产品在完整空间中的比例和气质。
2. 功能场景页：客厅、卧室、书房、玄关、厨房、浴室。
3. 材质工艺页：木纹、织物、金属、边角、连接结构。
4. 尺寸比例页：空间关系、人体局部对比、参数占位。
5. 收纳/承重/结构页：仅基于可见结构和用户参数。
6. 风格搭配页：不同软装或空间情绪。

模特方式：背影坐卧、手部触摸、局部使用状态，不露脸。

### 3C 数码 / 家电

推荐页面方向：

1. 科技质感首屏页：产品外观、屏幕、接口、结构。
2. 核心使用场景页：办公、学习、游戏、车载、厨房、卧室。
3. 功能结构页：按钮、接口、风道、屏幕、配件。
4. 操作交互页：手部操作，不露脸。
5. 参数规格页：未提供时用占位。
6. 套装/配件/收纳页：清单和场景。

模特方式：手部操作、背影办公、肩部以下使用，不露脸。

### 母婴 / 宠物

推荐页面方向：

1. 安心首屏页：柔和、干净、可信。
2. 使用场景页：儿童房、餐桌、外出、宠物角。
3. 材质/安全结构页：只用真实或占位信息。
4. 细节页：边角、开合、材质、清洁方式。
5. 尺寸/适用阶段页：未提供时用占位。
6. 收纳/携带/清洁页。

人物方式：默认不出现儿童正脸。可用成人手部、儿童背影、脚部、手部局部，儿童脸完全出画。

### 运动户外

推荐页面方向：

1. 场景爆发页：跑步、露营、骑行、健身、登山、旅行。
2. 穿戴/握持/使用关系页：无脸模特局部。
3. 材质结构页：防滑、扣具、织带、支撑、容量、轮廓。
4. 多场景适配页。
5. 参数规格页：重量、尺寸、容量等未提供则占位。
6. 购买理由收尾页。

模特方式：背影、手部、腿部、脚部、肩部以下动作，不露脸。

### 饰品珠宝 / 文玩礼品

推荐页面方向：

1. 质感首屏页：材质光泽、礼赠感、品牌氛围。
2. 佩戴局部页：手腕、锁骨以下、耳侧需避开脸部，优先用手腕和颈部以下。
3. 工艺细节页：纹理、镶嵌、打磨、串珠、扣件。
4. 场景礼赠页：礼盒、桌面、节日氛围。
5. 尺寸规格页：占位信息。
6. 信任收尾页：保养、包装、佩戴建议。

模特方式：手腕佩戴、手部托举、颈部以下裁切、背影礼赠，不露脸。

### 百货工具 / 收纳清洁

推荐页面方向：

1. 痛点解决首屏页：清洁、收纳、整理、效率。
2. 使用前后关系页：可以做状态对比，但不得伪造夸张效果。
3. 操作步骤页：手部操作，不露脸。
4. 结构细节页：刷头、卡扣、分区、容量、材质。
5. 多场景页：厨房、浴室、车内、办公室。
6. 规格收尾页：尺寸、清单、注意事项占位。

模特方式：手部操作、背影整理、局部动作，不露脸。

## 详情页页面数量决策

不要固定页数。按下面逻辑判断：

1. 简单低信息产品：4 到 5 页即可，重点做第一眼、场景、细节、规格、收尾。
2. 中等复杂产品：6 到 8 页，增加使用动作、局部细节、对比、参数和信任页。
3. 强功能或高客单产品：8 到 10 页，增加结构拆解、场景矩阵、参数规格、材质工艺、售后信任。
4. 跨境平台：优先 6 到 8 张高质量图文模块，文字更短，避免中文式密集堆字。
5. 内容电商：优先 5 到 7 页，首屏和场景页更强，文字更少更抓眼。

如果用户填了具体页数，必须按用户页数输出，但仍要保证每页有独立价值。

## 标准工作流

### 第一步：产品图精修成干净底图

如果原图背景混乱、光线差、主体不清晰，先用下面提示词得到干净底图。

```Plain
请把我上传的产品图精修成适合后续电商详情页生图参考的干净产品底图。严格保持产品原本的品类、轮廓、比例、结构、颜色、材质、表面工艺、Logo、包装和可见细节不变。背景处理为干净纯白、浅灰白或极简中性底色，去除杂物、水印、脏污、过曝、阴影混乱和无关元素。不要新增原图没有的按钮、接口、配件、包装、文字、纹理、装饰、功能结构或品牌元素。如果上传了多张同一产品不同角度图，只把它们作为同一产品外观补充参考，不要合成不存在的新结构。输出主体完整、边缘清晰、光影自然、真实可信、适合继续用于电商详情页生图参考的产品底图。
```

## 验收清单

每张图生成后按下面标准验收：

1. 产品品类、颜色、结构、比例、材质、Logo、包装是否与原图一致。
2. 多图参考是否仍然是同一产品，没有混成新款式或新结构。
3. 如果出现人物，是否完全不露脸，没有眼睛、鼻子、嘴、侧脸、半张脸或可识别身份。
4. 人物是否服务产品，而不是抢走主视觉。
5. 局部细节是否真实可信，没有虚构看不见的结构或材质。
6. 卖点是否可验证，没有编造功效、认证、销量、价格、排名。
7. 参数是否真实；信息不足时是否使用占位符。
8. 每页关键词、构图、页面职责和信息模块是否有差异。
9. 文字是否清晰、规范、无乱码、无错别字、无伪字。
10. 页面是否有品牌视觉系统，而不是廉价模板感。
11. 画幅、安全边距、文字大小和移动端可读性是否适合目标平台。
12. 详情页是否形成完整购买决策链：第一眼理解、场景代入、卖点解释、细节信任、规格收尾。
