# 05 带五点式卖点的电商详情页生成 SOP

## 适用目标

这套 SOP 用于把 `1 张产品图` 或 `多张同一产品不同角度图`，生成一整套电商产品详情页生图提示词。详情页中必须包含一个清晰的 `五点式产品卖点模块`，并且每个卖点自动配一个小标题。

最终产物不是单纯的 5 条文案，而是：

1. 产品外观锁定描述。
2. 五点式产品卖点总表。
3. 一整套详情页页面规划。
4. 每一页可直接交给生图工具执行的中文生图提示词。
5. 强制包含一页“五点式卖点总览页”，页面内展示 5 个卖点卡片，每个卡片都有小标题和短句说明。

适合：

1. 淘宝、天猫、京东、拼多多、抖音商城、小红书店铺等中文详情页。
2. Amazon A+、Shopee、Lazada、TikTok Shop 等跨境详情页或商品图模块。
3. 需要把产品图扩展成完整详情页长图，但又希望页面中有清晰卖点结构的场景。
4. 需要“先策划五点卖点，再把五点卖点落到详情页视觉页面里”的工作流。

不适合：

1. 只有模糊产品图，无法判断产品品类和主体外观。
2. 多个不同产品混在一起，但没有说明主推产品。
3. 需要写具体认证、检测、功效、销量、排名、价格、材质等级，但没有真实资料支撑。
4. 只想要平台后台商品 Bullet Points，不需要详情页视觉和生图提示词的情况。

## 核心原则

1. 这是一套详情页 SOP，不是五点文案 SOP；必须输出完整页面生图提示词。
2. 五点式卖点是详情页的核心信息模块，必须进入页面视觉，而不是只在文档里列出来。
3. 每个卖点必须自动生成一个小标题，小标题建议 4 到 8 个字，短、准、具体。
4. 五个卖点必须代表五个不同购买理由，不能重复表达。
5. 详情页页面之间要形成购买决策链：识别产品、理解价值、看到五点卖点、相信细节、代入场景、消除顾虑。
6. 不编造无法确认的参数、认证、功效、销量、排名、价格优势和材质等级。
7. 所有页面都必须保持产品外观一致，不改品类、不改结构、不改颜色、不新增原图没有的功能部件。
8. 详情页要像成熟电商设计稿，不要只是“产品居中 + 几行文字 + 空白背景”。

### 默认值规则

1. `平台` 为空：默认按淘宝 / 天猫详情页转化逻辑生成。
2. `输出语言` 为空：默认中文。
3. `详情页数量` 为空：默认生成 6 页；简单产品可 5 页，复杂产品可 7 到 8 页，但必须包含五点式卖点总览页。
4. `详情页比例` 为空：默认竖版 3:4 单页，后续可拼成长图。
5. `产品名称` 为空：根据图片识别保守品类名，不强行创造品牌名。
6. `品牌名称` 为空：页面中使用“品牌占位”或不出现品牌名。
7. `产品参数` 为空：只使用参数占位符，例如“待补充尺寸位”“待补充材质位”“规格以实物信息为准”。
8. `设计风格` 为空：根据品类、材质、价格带、目标人群和平台调性自动生成。
9. `禁止出现的内容` 为空：默认禁止虚假参数、绝对化承诺、错别字、乱码、无关道具、侵权品牌元素。

## 标准详情页结构

模型可根据产品特性调整页数和顺序，但必须包含“五点式卖点总览页”（推荐放在页面二）。

推荐结构：

1. 页面一：价值首屏  
   用于建立第一眼识别和核心购买理由。

2. 页面二：五点卖点总览  
   强制页面。把五个产品卖点做成 5 个信息卡片、5 个图标模块、5 个标签矩阵或 5 段分区说明。每个卖点必须有“小标题 + 短句说明”。

3. 页面三：核心卖点深化  
   从五点里选择最强的 1 到 2 个卖点，做成更有冲击力的视觉说明页。

4. 页面四：结构 / 材质 / 细节页  
   展示可确认的结构、材质、工艺、局部细节或使用方式，不编造看不见的信息。

5. 页面五：场景代入页  
   把产品放进真实使用场景，让用户理解适合谁、什么时候用、解决什么问题。

6. 页面六：参数 / 包装 / 信任收尾页  
   有真实参数就展示；没有真实参数就用占位符。可加入包装、配件、售后、注意事项或购买顾虑处理。

如果产品很简单，可以合并页面三和页面四；如果产品复杂，可以把五点卖点分别拆成多个深化页。但不能删除“五点卖点总览页”。

## 五点式卖点模块规则

五点卖点总览页必须满足：

1. 页面内必须出现 5 个卖点，不多不少。
2. 每个卖点必须有小标题。
3. 每个小标题建议 4 到 8 个字，必须贴合当前产品。
4. 每个卖点配 1 句短说明，建议 8 到 18 个字，适合放在图内。
5. 五个卖点的视觉权重要均衡，不能只突出其中一个，其他四个变成角落小字。
6. 可以使用 5 宫格、环形信息矩阵、阶梯式信息流、左右分栏、产品环绕标签、图标卡片阵列等版式。
7. 页面中必须明确要求中文清晰可读、无错别字、无乱码、无伪字。

五点卖点方向优先级：

1. 核心功能：产品最主要解决的问题。
2. 用户利益：省时、省力、舒适、便携、耐用、好清洁、好收纳等。
3. 可见细节：结构、开合、分区、边角、纹理、接口、把手、刻度等。
4. 材质工艺：只有图片可确认或用户明确提供时才写。
5. 使用场景：家庭、办公、旅行、户外、厨房、宠物、母婴、送礼等。
6. 规格适配：尺寸、容量、型号、配件，仅限用户提供或明确可确认。
7. 信任顾虑：售后、包装、清洁、安装、维护、注意事项，仅限可信表达。

避免使用的小标题：

```Plain Text
品质优选
精选好物
使用方便
多场景适用
高端大气
匠心工艺
贴心设计
放心选择
```

更好的小标题方向：

```Plain Text
分区收纳
一拎即走
稳固承托
细口控量
冷热都装
柔软亲肤
桌面不乱
开盖即用
```

请在后台静默完成以下工作，不要输出分析过程：

1. 每一页提示词都必须以“以用户上传的产品图作为唯一外观参考，严格复刻产品原貌”作为开头约束。

4. 不得新增原图中不存在的按钮、接口、部件、纹理、图案、装饰、配件、功能结构或品牌元素。
5. 如果图片看不清背面、内部结构、隐藏功能或配件，不要编造。

信息真实规则：
1. 只能使用图片可确认的信息、用户明确填写的信息和高置信度品类常识。
2. 看不清或无法确认的尺寸、功率、容量、成分、认证、型号、价格、销量、环保等级、适用年龄、产地、材质等级、具体功效，禁止编造。
3. 信息不足但页面需要完整时，使用“待补充参数位”“待补充规格位”“以实物信息为准”等占位表达。
4. 图内文案禁止使用“最强、第一、顶级、永久、100%、全网最低、医学级、国家级认证、零风险”等绝对化词，除非用户提供真实依据。

五点卖点总览页硬性要求：
1. 必须单独输出一页，页面标题可以根据产品自动拟定，例如“5 大核心卖点”“一页看懂优势”“五重购买理由”等，但要贴合产品。
2. 页面内必须出现 5 个卖点卡片或 5 个信息区块。
3. 每个卖点区块必须包含一个 4 到 8 字的小标题和一句 8 到 18 字的短说明。
4. 五个小标题必须具体，不能使用“品质优选、精选好物、使用方便、多场景适用、高端大气、匠心工艺”等泛词。
5. 页面必须说明版式：5 宫格、环形矩阵、阶梯卡片、左右分栏、产品环绕标签或其他适合当前产品的成熟排版。
6. 页面必须强调中文清晰可读、无乱码、无错别字、无伪字，文字自然融入版式。

详情页设计规则：
1. 详情页比例读取用户输入区；未填写时默认竖版 3:4。
2. 每一页都要像成熟品牌详情页设计稿，不能只是单张海报或简单文字说明。
3. 每一页至少包含 3 个信息层级，例如主标题、副标题、卖点标签、说明短句、参数占位、编号、引导线、底部信息条等。
4. 页面之间必须属于同一套品牌视觉系统，但每页构图、信息重点和阅读路径要不同。
5. 背景要有材质、空间层次和光影结构，不要只有纯色空白背景。
6. 产品主体建议占画面 35% 到 60%；局部细节页可以更高，但仍要保留信息区域。
7. 图内文字必须短句化、模块化、层级清晰，不能堆成长段。

## 返修提示词

### 只输出了五点文案，没有输出详情页

```Plain Text
上一版方向错误。我要的是“带五点式产品卖点模块的电商详情页生图提示词”，不是单独五点文案。请保留五点卖点作为详情页页面二的核心模块，并补全整套详情页页面提示词：价值首屏、五点卖点总览、核心卖点深化、结构细节、场景代入、参数信任收尾。
```

### 五点卖点页太像文字表格

```Plain Text
请重做“五点卖点总览页”。不要做成简单文字表格，要做成成熟电商详情页视觉：5 个卖点卡片或环形信息矩阵，结合产品主体、图标、编号、引导线、背景材质和光影。每个卖点保留小标题和短句说明，中文必须清晰可读。
```

### 页面太模板化

```Plain Text
请基于上一版提升整套详情页设计完成度。不要只做产品居中、纯色背景、几行标题。每一页都要有不同构图、信息层级、背景材质、光影结构和商业排版，同时保持同一套品牌视觉系统。
```

### 卖点太泛

```Plain Text
请重写五点式产品卖点总表和对应页面表达。问题是卖点太泛，换个产品也能用。请让每个卖点更贴合当前产品的品类、结构、材质、功能、使用场景和用户痛点，但不要增加没有依据的新参数和新功效。
```

### 信息有虚构风险

```Plain Text
请检查上一版所有页面中的参数、材质、认证、功效、销量、排名、价格优势、适用范围和绝对化表达。凡是无法从产品图或用户资料确认的内容，都删除或改成“待补充参数位”“以实物信息为准”等保守表达。
```

### 产品外观跑偏

```Plain Text
请基于上一版重写所有页面提示词，最高优先级是产品外观一致。必须严格回到用户上传产品图，保持品类、轮廓、结构、比例、颜色、材质、Logo、包装和可见细节不变。可以优化场景、光影和排版，但不得改造产品本身。
```

## 验收清单

生成后按下面清单验收：

1. 是否输出了产品外观锁定描述。
2. 是否输出了五点式产品卖点总表。
3. 是否输出了完整详情页生图提示词，而不是只有五点文案。
4. 是否包含“五点卖点总览页”。
5. 五点卖点总览页是否正好 5 个卖点，每个都有小标题和短句说明。
6. 五个小标题是否具体，是否避免了泛化模板词。
7. 页面之间是否有购买决策链，而不是重复堆卖点。
8. 每一页是否写清构图、镜头、产品位置、背景材质、光影、文字排版和信息模块。
9. 产品外观是否全程保持一致，没有跑品、改色、改结构、加不存在的部件。
10. 是否没有编造参数、认证、功效、销量、排名、价格优势和材质等级。
11. 图内中文是否明确要求清晰可读、无乱码、无错别字、无伪字。
12. 整套详情页是否能直接交给生图工具逐页生成。

## 最终合格标准

一套合格的结果应该满足：

1. 它是一套详情页生成方案，不是单独五点文案。
2. 五点式卖点成为详情页中的一个核心视觉页面。
3. 每个卖点都有清楚的小标题和图内短句。
4. 整套页面既能讲清产品优势，又能保持电商设计完成度。
5. 信息可信、产品不跑偏、页面可执行、后期可直接进入生图和排版流程。
