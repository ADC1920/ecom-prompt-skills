# 产品场景图单一核心场景生成 SOP

## 适用场景

这份 SOP 用于生成电商产品场景图，核心逻辑是：`1 个核心场景 + 统一风格`。

适合：

1. 商家要给产品生成一套视觉统一的场景主图。
2. 工具里需要提供“类目高频场景”给用户选择。
3. 用户没有对标图，只知道产品类目，希望快速选一个最常用、最合理的场景。
4. 同一个产品或同一批产品要复用同一个场景风格，避免主图组视觉混乱。

不适合：

1. 一张图里混多个场景。
2. 每张图都随机换一个背景。
3. 平台严格白底首图。
4. 详情页信息海报、参数图、促销图。
5. 真实手机买家秀；这类需求优先使用 《上传产品批量生成相同场景真实手机买家秀 SOP》。

## 核心原则

场景图大多应该选择 `1 个核心场景 + 统一风格`。

例如：

1. 卖户外帐篷，固定“露营草地场景”。
2. 卖厨房用品，固定“现代厨房场景”。
3. 卖女装，固定“通勤办公室 / 周末咖啡馆 / 户外公园”中的一个。
4. 卖美妆护肤，固定“梳妆台 / 浴室洗手台 / 晨间护肤桌面”中的一个。

这样整套主图视觉统一，用户不会觉得每张图来自不同店铺、不同品牌或不同拍摄方案。

硬规则：

1. 同一张场景图里不要混多个场景。
2. 同一组场景图默认复用同一个核心场景。
3. 批量生成时，可以变化产品角度、镜头远近、局部特写、道具位置和构图，但不能切换到另一个空间。
4. 如果确实需要多场景，应该把不同场景分散在不同主图、不同页面或不同任务里，每张图仍然只表达一个场景。
5. 场景必须服务产品真实使用关系，不能暗示产品不存在的功能、尺寸、配件、效果或使用方式。

## 工具内场景选择逻辑

产品场景图工具建议这样设计：

1. 用户上传产品图。
2. 工具识别或让用户填写产品类目。
3. 工具展示该类目的高频场景选项。
4. 用户只选择 1 个核心场景。
5. 后续生成的所有场景图复用这个核心场景。
6. 如果用户选择“多场景”，工具应提示：多场景会拆成多张图，不会混在同一张图里。

推荐选项文案：

```Plain Text
请选择 1 个核心场景作为本组图片的统一场景。为了保证主图组视觉统一，同一张场景图里不会混合多个场景；如果需要多场景，会拆到不同主图里分别生成。
```

## 多场景需求处理

如果用户确实要多场景，不要让 AI 在同一张图里混场景，而是拆成不同图片任务。

正确做法：

1. 场景图一：现代厨房台面。
2. 场景图二：餐桌早餐场景。
3. 场景图三：办公室零食角。

错误做法：

1. 一张图里同时出现厨房、办公室、户外、公园。
2. 同一组图每张随机换背景，没有统一风格。
3. 为了展示“多场景适用”，把产品复制成多个小图拼贴在同一张图里。

多场景返修提示词：

```Plain Text
请不要把多个场景混在同一张产品场景图里。请把每个场景拆成独立主图，每张图只保留 1 个核心场景。当前这一张只保留【填写场景】，删除其他场景元素，保持产品外观与上传图一致。
```

## 批量生成操作

### 同一个产品生成统一场景图组

1. 上传同一组产品图。
2. 选择 1 个固定核心场景。
3. 用总控提示词输出多条生图提示词。
4. 每条提示词单独生成一张图。
5. 检查每条提示词是否都复用了同一个场景基准描述。
6. 翻车时只返修单张，不要整组重做。

### 多个产品复用同一场景

如果多个产品要统一品牌视觉，可以使用同一个固定核心场景和同一套提示词结构。

通用提示词：

```Plain Text
以上传产品图作为唯一产品外观依据，严格保持产品真实品类、轮廓、比例、结构、颜色、材质、包装、品牌露出、标签和所有可见细节不变。为该产品生成一张统一风格的产品场景图，固定核心场景为：【填写一个具体场景，例如现代厨房灰色石英石台面 / 露营草地木质折叠桌 / 通勤办公室白色办公桌】。整组产品都复用同一个场景空间、同一背景材质、同一主光方向、同一色温、同一道具体系和同一商业摄影风格。产品自然出现在画面中，占画面约 35%-55%，有真实接触阴影、合理透视和真实尺度。道具只用于营造空间层次和真实使用氛围，不遮挡产品，不暗示不存在的功能。不要生成无关文字、乱码、水印、平台 Logo、价格标签、促销贴纸、参数卡片和详情页排版。不要改变产品外观，不要新增产品图中没有的配件、功能、规格、认证、品牌信息或包装文字。high-end commercial product photography, realistic scene, unified style, natural lighting, premium composition, product accurate, hyper-detailed, 8k, 【按输出比例填写，默认 --ar 1:1】
```

## 验收清单

生成后逐张检查：

1. 是否只使用了 1 个核心场景。
2. 同一组图的背景、光线、色温、道具体系和视觉风格是否统一。
3. 多张图之间是否只是构图、角度、远近、产品状态和局部展示不同，而不是场景乱跳。
4. 产品是否与上传图一致，没有变色、变形、换包装、改结构。
5. 产品是否是第一视觉中心，没有被道具、人物或背景抢走。
6. 场景是否符合产品真实用途，没有暗示不存在的功能。
7. 是否没有无关文字、乱码、水印、价格、促销标签和平台 Logo。
8. 如果不允许人物，是否完全没有人物、手脚和身体局部。
9. 如果允许无脸模特，是否没有眼睛、鼻子、嘴、侧脸、半张脸和可识别人脸。

## 常用返修提示词

### 场景混乱

```Plain Text
请把这组产品场景图统一回 1 个固定核心场景：【填写场景】。整组图必须保持同一空间、同一背景材质、同一光线方向、同一色温、同一道具体系和同一商业摄影风格。只允许变化产品角度、镜头远近、局部特写、道具轻微位置和构图，不要切换到其他场景。
```

### 一张图里混了多个场景

```Plain Text
请删除同一张图里的其他场景，只保留一个核心场景：【填写场景】。不要在一张图里同时出现厨房、办公室、户外、咖啡馆等多个空间。产品外观保持与上传图一致，场景服务产品展示。
```
