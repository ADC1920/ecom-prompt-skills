# 模特换头换装&批量不同姿势模特图教程

> 合规提示：上传真实人脸或模特照片前，确认已取得该人物的肖像使用授权；生成结果仅限自有产品推广素材使用，不得冒充真实买家秀或用于误导性宣传。

## 这份教程现在怎么用最顺

这版教程只分两条线：

1. `单张图` 直接用 `Gemini`

2. `批量多张图 / 不同姿势 / 连续出图` 先用 `Gemini` 跑通 1 张，再把稳定提示词拿去生图网站批量用

也就是说：

1. 你只做 1 张图，不要绕，直接让 `Gemini` 干

2. 你要做一整套不同姿势，再考虑生图网站

---

## 教程一：模特换头

### 什么时候直接用 Gemini

当你只做 1 张图时，直接上传：

1. 模特底图

2. 新人脸图

然后配下面这段提示词：

```Plain Text
你是一名顶级人物修图导演、商业换头修图专家。

我现在会上传两类图片：
1. 模特底图
2. 要替换进去的人脸照片

你的任务不是重做整个人物，而是直接基于底图完成换头，只替换头部 / 面部区域。

请注意：
1. 必须锁定底图中的身体、姿势、服装、构图、背景、光线和动作。
2. 只替换头部 / 脸部区域，不改变人物整体姿势。
3. 必须严格参考新人脸图，保留其五官特征、脸型、发际线特征和人物识别感。
4. 要让脸部角度、光线、肤色、颈部衔接、耳朵、头发边缘与原图自然融合。
5. 如果新人脸图角度与底图差异太大，只能保守调整，不能乱拼。
6. 头部要和身体协调，不要头大身子小，或者头小身子大。

请在后台静默完成以下动作，不要输出分析过程：
1. 识别底图人物姿势、头部朝向、镜头角度、光线方向和背景氛围。
2. 识别新人脸图的五官、脸型、发际线、肤色和角度特点。
3. 判断这次换头最容易翻车的地方，例如发际线、耳朵、下颌线、脖颈、肤色、头发边缘、脸部透视。
4. 直接完成这张图的换头生成。

请严格遵守以下规则：

一、底图锁定规则
1. 保留底图中的身体、姿势、服装、背景、光线、动作和构图。
2. 不要重画整个人，只替换头部 / 面部。
3. 不要改变身体朝向和镜头关系。

二、人脸锁定规则
1. 必须严格参考新人脸图保留五官识别度。
2. 不要把新人脸做成另一个人。
3. 如果新人脸图中头发信息不完整，优先服从底图发型结构，再尽量保留脸部识别特征。

三、融合规则
1. 必须统一肤色、光线、阴影、锐度、皮肤质感。
2. 发际线、耳朵、下巴、脖颈和头发边缘必须自然。
3. 不允许出现头大头小、脸歪、五官漂移、脖子断裂、耳朵缺失、皮肤拼接感。

四、输出规则
1. 直接输出换头后的图片，不要只给原理。
2. 如果你必须补充说明，只允许在图片后补一句“若需继续修正，优先修哪些部位”。
```

### 如果单张图第一次不稳，再补一刀

```Plain Text
请继续强化这次换头的自然融合感，重点修正：发际线、耳朵、脸部透视、下颌线、脖颈衔接、肤色统一、头发边缘、光线方向和阴影过渡。必须像同一次真实拍摄，而不是后期拼接。
```

## 教程二：模特换装

### 什么时候直接用 Gemini

当你只做 1 张图时，直接上传：

1. 模特底图

2. 服装产品图

然后配下面这段提示词：

```Markdown
你是一名顶级服饰视觉修图导演、商业模特换装策划师。

我现在会上传两类图片：
1. 模特底图
2. 要换到模特身上的服装产品图

你的任务不是重新生成一个新模特，而是直接基于我上传的原图关系，完成这张图的模特换装。

请注意：
1. 必须锁定原模特的姿势、动作、镜头角度、构图、背景、光线、表情和身体比例。
2. 只替换服装，不改变模特身份和场景。
3. 必须严格参考产品图，还原服装的颜色、版型、面料质感、领口、袖型、门襟、口袋、衣长、裤长、褶皱逻辑和结构细节。
4. 如果产品图中看不清背面、内里、下摆、袖口等结构，不要乱编。
5. 如果手臂、头发、包、道具压住了服装区域，要处理得合理自然，不要穿帮。

请在后台静默完成以下动作，不要输出分析过程：
1. 识别模特姿势、镜头角度、光线和场景。
2. 识别产品图里的服装结构、颜色、材质和版型重点。
3. 判断这张图最容易翻车的部位，例如领口、肩线、胸口、袖口、腰线、裤裆、裙摆、脚踝、手部遮挡。
4. 直接完成这张图的换装生成。

请严格遵守以下规则：

一、模特锁定规则
1. 保留原模特的脸、头发、姿势、动作、身体比例、镜头角度和背景。
2. 不要把模特整体重画成另一个人。
3. 不要改变表情、妆容和身体朝向，除非服装遮挡关系必须微调。

二、服装锁定规则
1. 必须严格参考产品图还原服装。
2. 不能擅自改颜色、改版型、改面料、改图案、改长度、改结构。
3. 不能把宽松款改成修身款，也不能把修身款改成廓形款。
4. 如果图中信息不足，只能保守延展。

三、编辑结果规则
1. 最终效果要像真实拍摄，不要像贴图。
2. 服装和身体结构必须匹配，肩线、胸线、腰线、袖子和下摆必须自然。
3. 光线方向、阴影、皮肤与服装接触区域必须真实。
4. 不要出现漂浮衣服、断裂衣服、手穿模、头发穿模、边缘糊掉。

四、输出规则
1. 直接输出换装后的图片，不要只给原理。
2. 如果你必须补充说明，只允许在图片后补一句“若需继续修正，优先修哪些部位”。
```

### 如果单张图第一次不稳，再补一刀

```Plain Text
请继续强化这次换装的真实感，重点修正：服装与身体贴合关系、肩线、领口、袖口、腰线、褶皱走向、阴影方向、手部遮挡和头发压住衣服的边缘细节。必须让结果更像真实拍摄，不要像把衣服贴在模特身上。
```

## 如何批量调整模特姿势

进入三万图ai的拆页模式，新建多个任务卡，上传真人模特图和建模姿势图。

```Plain Text
请分析我提供的两张参考图（一张真人图，一张3D建模图），并严格按照以下规则生成一张全新的摄影级图像：
**1. 提取与保留（来自真人图）：** 完全复刻真人图中模特的五官特征、发型、穿着的服饰（包括款式、材质和颜色）。保留真人图中的光影质感与背景风格（如干净的纯色背景或工作室布光）。
**2. 姿势与构图（来自建模图）：** 让模特摆出与建模图完全一致的动作。**【核心强制要求】**：画面的景别、取景范围、边缘裁切位置、摄像机视角必须与建模图**绝对对齐**。如果建模图是半身（例如卡在胯部），最终生成的画面也必须在相同的位置裁切，绝不允许自行脑补或延伸出未展示的下半身/全身。
**3. 排除与忽略（绝对禁止）：**
不要参考建模图的灰色背景、3D塑料材质和非真人身体比例。
不要参考真人图原本的站姿和全身构图。
```
