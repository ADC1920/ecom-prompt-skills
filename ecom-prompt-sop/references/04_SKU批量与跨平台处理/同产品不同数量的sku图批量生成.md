# 同产品不同数量的sku图批量生成

适用场景：先用产品图生成一张标准 SKU 图，再基于这张标款 SKU 图，批量生成同一产品不同数量的套装 SKU 图，例如 3 件套、5 件套、8 件套。

核心原则：先做一张标款图，再基于标款图改数量。后续套装图只改“产品数量”和“图中数量描述”，不要重新设计版式。

## 第一步：生成 SKU 标款图

### 生成标款生图提示词

把一张或多张同一产品的产品图上传给任何一个多模态AI，然后复制下面提示词：

```Plain Text
你是一名电商顶级美工和 SKU 图提示词专家。

我会上传一张或多张同一产品的产品图。请你先识别产品的真实特性，再帮我生成一条可直接用于 AI 生图工具的“SKU 标款图1:1比例生图提示词”。

请严格遵守以下要求：
1. 只根据我上传的产品图识别产品，不要脑补图中看不出来的信息。
2. 不要编造品牌、价格、销量、认证、功效、材质、尺寸、赠品、服务承诺。
3. 如果你认为生成 SKU 图缺少必要信息，请先用“需要补充的信息”列出来，提示我补充后再生成生图提示词。
4. 如果缺少的信息不影响先生成通用标款图，请使用“待补充信息占位”处理，不要乱写。
5. 最终提示词要适合生成一张电商 SKU 标款图。画面要有设计感，必须具备：清晰产品主体、稳定信息布局、标题区、卖点区、数量/规格区和服务/权益区。
6. 这张标款图后续会用来批量生成不同数量的套装图，所以版式要稳定，不能做成只适合某一个数量套餐的一次性海报。

请按下面格式输出：

## 产品识别摘要
简要说明你识别到的产品品类、外观、颜色、材质质感、可见卖点，以及不能确定的信息。

## 需要补充的信息
列出你认为会影响 SKU 图准确性的关键信息。如果没有必须补充的信息，就写“暂无必须补充信息，可先生成通用标款图”。

## SKU 标款图生图提示词
输出一段可直接复制到 AI 生图工具的中文提示词。提示词必须包含：产品主体要求、画面比例、信息布局、标题区、卖点区、数量/规格区、服务/权益区、背景风格、文字清晰度、禁止脑补信息。
```

### 生成标款图

操作：

1. 复制多模态AI输出的 `SKU 标款图生图提示词`。

2. 打开三万图 AI 或其他 AI 生图工具。

3. 上传同一产品图作为参考图。

4. 粘贴生图提示词。

5. 生成 SKU 标款图。

标款图验收：

1. 产品外观没有变形、变色、缺件、错结构。

2. 图中信息布局清晰，适合后续改成 3 件、5 件、8 件等套装图。

3. 文字尽量清晰，没有严重乱码、错字、重影、裁切。

4. 没有编造价格、销量、认证、功效、赠品等未提供信息。

5. 版式不是一次性海报，而是一张可复用的 SKU 标款图。

## 第二步：批量生成同产品不同数量的套装图

上传第一步生成的标款 SKU 图，粘贴下面提示词。

说明：下面是按关键词（页面 x：标题）拆成 3 个任务。如果还有其他套餐数量，就按同样格式继续增加页面提示词。

```Plain Text
页面一：产品数量 3
不改变信息布局，所有产品的大小要一致，帮我把 SKU 图中的产品数量增加到 3。如果图中有数量描述，请一并修改成与画面一致的数量表达。

页面二：产品数量 5
不改变信息布局，所有产品的大小要一致，帮我把 SKU 图中的产品数量增加到 5。如果图中有数量描述，请一并修改成与画面一致的数量表达。

页面三：产品数量 8
不改变信息布局，所有产品的大小要一致，帮我把 SKU 图中的产品数量增加到 8。如果图中有数量描述，请一并修改成与画面一致的数量表达。
```

## 增加更多套餐数量的写法

```Plain Text
页面一：产品数量 3
不改变信息布局，所有产品的大小要一致，帮我把 SKU 图中的产品数量增加到 3。如果图中有数量描述，请一并修改成与画面一致的数量表达。

页面二：产品数量 5
不改变信息布局，所有产品的大小要一致，帮我把 SKU 图中的产品数量增加到 5。如果图中有数量描述，请一并修改成与画面一致的数量表达。

页面三：产品数量 8
不改变信息布局，所有产品的大小要一致，帮我把 SKU 图中的产品数量增加到 8。如果图中有数量描述，请一并修改成与画面一致的数量表达。

页面四：产品数量 2
不改变信息布局，所有产品的大小要一致，帮我把 SKU 图中的产品数量增加到 2。如果图中有数量描述，请一并修改成与画面一致的数量表达。

页面五：产品数量 10
不改变信息布局，所有产品的大小要一致，帮我把 SKU 图中的产品数量增加到 10。如果图中有数量描述，请一并修改成与画面一致的数量表达。
```

## 最终检查

每张套装图生成后，检查下面 5 点：

1. 产品数量是否正确：3 件套就必须出现 3 个产品，5 件套就必须出现 5 个产品。

2. 数量文案是否同步：图中不能一边写 3 件套，一边画 5 个产品。

3. 信息布局是否保留：标题区、卖点区、规格区、服务区不能乱跑。

4. 产品外观是否一致：不能改颜色、改包装、改结构、加不存在的配件。

5. 文字是否可读：不能有乱码、错字、变形、重影或裁切。

不合格时，只返修对应页面，不要整套重新生成。

## 常用返修提示词

### 产品数量错了

```Plain Text
请只修正这一页的产品数量。当前页面应为【填写数量】件套，画面中必须清晰出现【填写数量】个同款产品。保留原 SKU 标款图的信息布局、背景、字体层级和卖点区位置，不要改变产品外观，不要重新设计整张图。
```

### 数量文案没同步

```Plain Text
请只修正图中与数量相关的文字。当前页面应统一表达为【填写数量】件套或【填写数量】件装，画面中的产品数量也必须与文字一致。其他版式、背景、产品外观和卖点信息保持不变。
```
