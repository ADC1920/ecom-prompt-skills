# 多产品替换流程（含提示词创作过程）

**适用场景：**纯产品场景无文字信息布局，图片多产品替换。

**需要准备：**一张对标场景图、一张或者多张不同产品的白底图。

## 操作方法

1. 复制下方的提示词并上传对标图以及一张或者多张不同产品的白底图，一起发给一个多模态AI。

2. 把得到的生图提示词加上你的产品图用于生成类似风格场景的产品场景图。

**提示词**
```Plain Text

**请扮演一位专业的电商视觉与 AI 生图提示词工程师。**

我的目标是将特定的【核心产品】无缝融入到特定的【参考场景】中，并生成高质量的英文生图提示词（适用于 Midjourney 或 Stable Diffusion）。

**任务规则：**

1. **场景解析：** 准确提取【参考场景】中的环境背景、空间结构、光影氛围、人物特征及画面构图。

2. **产品解析：** 准确提取【核心产品】的材质、颜色、几何形态和设计风格。

3. **融合重构：** 将核心产品替换进场景中，确保透视关系正确，物理交互（如光线反射、阴影）符合现实逻辑。

4. **输出规范：** 生成一条超写实、高分辨率的英文摄影级提示词。包含明确的结构：`[主体产品细节] + [场景与人物动作] + [光影与色彩环境] + [摄影参数/渲染风格]`。

5. **限制：** 仅输出纯英文提示词，不需要输出中文翻译，也不要输出任何多余的解释和过渡语。

6. **多产品处理：** 如果上传了多张不同产品的白底图，为每个产品分别输出一条独立的英文提示词，逐条把【核心产品】替换为对应产品，不要把多个产品写进同一条提示词。




```
