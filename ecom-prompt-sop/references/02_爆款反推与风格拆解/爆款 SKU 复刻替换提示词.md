# 爆款 SKU 复刻替换提示词

## 适用场景

你有一个产品的多张源图，同时有一张想复刻的爆款对标 SKU 图。目标不是简单换颜色，而是把自己的产品放进对标图已经成立的爆款版式、背景、构图、信息布局和商业氛围里，同时把图中文字改成适合自己产品的真实表达。

## 使用素材

1. 一个产品的多张源产品图：用于提取同一个产品的真实主体。
2. 一张对标爆款 SKU 图：用于作为底图模板和版式模板。
3. 可选补充信息：产品名称、品牌名、颜色名称、规格参数、核心卖点、促销权益、服务保障。

## 直接复制用的提示词

```Plain Text
请严格区分两类参考图的角色：

1. 对标爆款 SKU 图是底图模板和版式模板。请保留它的画幅比例、背景、构图、产品摆放机位、透视关系、光线方向、阴影逻辑、道具、场景氛围、色彩秩序、文字排版结构、信息模块位置和整体商业完成度。

2. 多张源产品图只用于提取同一个产品的真实主体信息。请综合多张源图中最清晰、最一致的产品外观，准确提取产品品类、轮廓、颜色、材质、结构、包装、Logo、纹理、比例、配件和关键可见细节。不要参考源产品图的背景、桌面、构图、拍摄角度、光线、阴影、杂物或场景。

请把对标爆款 SKU 图中的原商品主体替换为源产品图中的产品主体。替换后的产品必须自然融入对标图的机位、透视、光线、阴影和场景中，尺寸占比、摆放角度和画面重心要参考对标图原商品的位置关系；但产品外观必须以源产品图为准，不能只把原商品改成源产品的颜色，也不能保留原商品的结构、包装、材质或品类特征。

请同步改写对标爆款 SKU 图中的信息布局和文案内容：保留对标图的信息模块位置、字号层级、标题区、卖点区、参数区、促销区、角标、底部权益条和字体风格，但文案必须改成适合源产品的真实表达。

对标图里的通用促销词、服务词可以保留或轻微改写；对标图里绑定原商品品类、功能、参数、材质、容量、规格、认证、价格、销量和颜色的文字，不得照搬，必须根据源产品可见信息或用户提供信息改写。

如果无法从源产品图或补充信息中确认某项内容，请使用“【主卖点标题】”“【核心卖点1】”“【真实参数】”“【服务保障】”“【促销权益】”这类占位文案替代，不要编造。

如果对标图中的颜色文字、品类标题、规格参数、卖点标签或产品数量描述与源产品不一致，必须改成源产品对应的信息；如果源产品有品牌或包装文字，请尽量保留真实品牌露出。如果没有明确品牌，可使用“自定义”作为品牌占位。

禁止交换两类参考图的角色；禁止参考源产品图的场景；禁止把多张源图拼成多产品合集；禁止生成左右对比图、前后对比图、拼图、过程图或设计稿；禁止只改颜色；禁止添加源产品图中不存在的结构、配件、包装、功能、参数、认证或功效。

最终只输出一张自然真实、信息清晰、适合电商平台使用的爆款复刻 SKU 成图。画面应像真实拍摄和专业电商设计完成图，产品准确，文字可读，背景和版式接近对标爆款图，信息内容适配源产品。
```

## 验收清单

1. 对标爆款 SKU 图的背景、构图、光线、道具、版式和信息模块位置是否被保留。
2. 源产品图只影响产品主体，是否没有继承源图背景、桌面、拍摄角度和杂物。
3. 产品外观、颜色、材质、结构、包装、Logo、比例和关键细节是否准确。
4. 图中文字是否已改成适合源产品的信息，是否没有照搬对标商品的专属卖点。
5. 未确认的参数、认证、价格、销量、功效是否没有被编造。
6. 成图是否不是拼图、对比图、过程图，也不是只改颜色。

## 常用返修提示词

### 产品主体不准确

```Plain Text
请只修正产品主体。产品外观必须以源产品图为准，严格恢复源产品的颜色、材质、结构、包装、Logo、比例和关键细节；保留当前对标爆款图的背景、构图、光线、道具、版式和信息模块位置，不要重新设计整张图。
```

### 错误继承了源图背景

```Plain Text
请删除源产品图带入的背景、桌面、杂物、拍摄角度和光线，只保留源产品主体。画面背景、构图、机位、光线、阴影、道具和场景氛围必须回到对标爆款 SKU 图的模板效果。
```

### 文案照搬了对标商品

```Plain Text
请只修正图中文字。保留当前文字模块的位置、字号层级、字体风格和信息布局，但删除不适合源产品的原商品品类词、功能词、参数、规格、认证、价格、销量和颜色描述。无法确认的信息改为“【主卖点标题】”“【核心卖点1】”“【真实参数】”“【服务保障】”“【促销权益】”等占位文案，不要编造。
```
