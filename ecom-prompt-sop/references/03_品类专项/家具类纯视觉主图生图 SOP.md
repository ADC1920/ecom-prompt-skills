# 家具类纯视觉主图生图 SOP

## 适用品类说明

适合：

1. 沙发、床、床垫、餐桌、茶几、电视柜、书桌、椅子、衣柜、鞋柜、斗柜、置物架等家具产品。

2. 需要生成电商主图、平台头图、商品轮播图，但不想在图片里放任何文字、标签、参数、卖点卡或促销信息的家具类产品。

3. 适合走真实空间感、材质质感、居家氛围、风格搭配和产品高级感的主图。

4. 适合淘宝、天猫、京东、抖音、小红书商城等平台的 `1:1` 方图主图，也可按平台需要扩展为 `3:4` 竖图。

不太适合：

1. 必须展示价格、活动、参数、尺寸标注、功能卖点、服务承诺的信息型主图。

2. 产品外观不清晰、结构被遮挡严重、材质无法判断的模糊图片。

3. 需要做详情页信息排版、对比矩阵、尺寸结构图的场景。

## 核心要求

本 SOP 的核心目标是：生成一套“纯视觉家具主图”，严格做到“纯视觉，只有产品和场景，无文字信息布局”。

画面里只能出现：

1. 家具产品本体。

2. 与家具风格匹配的真实空间场景。

3. 少量合理道具，例如地毯、绿植、抱枕、床品、餐具、书本、台灯、装饰画、窗帘等。

4. 自然光影、地面、墙面、窗户、软装、空间层次。

画面里禁止出现：

1. 任何中文、英文、数字、品牌字样、Logo、商标、价格、促销词。

2. 任何标题、副标题、卖点标签、参数卡、信息框、角标、徽章、底部条。

3. 任何尺寸线、箭头、引导线、图标、表格、对比栏、UI 面板。

4. 任何二维码、条形码、水印、平台元素、边框、海报排版装饰。

5. 任何不属于产品和真实场景的平面设计信息布局。

## 使用前准备

推荐准备：

1. 至少 1 张主体完整、角度清晰、无遮挡的家具实拍图或白底图。

2. 最好补充 2 到 4 张辅助图：正面、侧面、局部材质、打开/收纳结构、真实摆放图。

3. 如果产品有明确风格，可以补充：现代简约、奶油风、原木风、意式轻奢、北欧风、侘寂风、新中式、复古风、工业风、儿童房风格等。

4. 如果没有补充风格，让 Gemini 根据产品外观自动判断，但不能改变产品真实颜色、材质和结构。

## 第一步：实拍图转干净产品底图

把家具产品图发给 AI，并附上下面这段提示词：

```Plain Text
请帮我把这张家具产品图精修成干净、真实、适合后续电商纯视觉主图生成的产品底图。

要求：
1. 保持家具原本的品类、轮廓、比例、结构、颜色、材质纹理、腿部结构、扶手、靠背、桌面、柜门、抽屉、床头、软包、五金件等关键部位不变。
2. 背景处理为干净纯白、浅灰白或极简室内底色，不要加入多余道具，不要改变产品真实外观。
3. 如果原图有木纹、布纹、皮纹、岩板纹、金属反光、玻璃边缘、藤编纹理、软包缝线，请尽量保留清晰。
4. 不要擅自新增产品没有的功能结构，例如隐藏抽屉、可升降装置、灯带、按摩功能、电动结构、额外五金件。
5. 输出一张主体完整、边缘清晰、光影自然、适合作为后续家具主图统一外观参考的产品图。
6. 画面中不要出现任何文字、Logo、水印、标签、参数、促销元素或信息排版。
```

## 第二步：Gemini 直出家具类纯视觉主图整套生图提示词

### 作用

通过 `1 到 5 张` 家具产品参考图 + 下方总控提示词，让 Gemini 一次性输出：

1. `6` 张标准纯视觉主图中文生图提示词。

2. `2` 张可选增强纯视觉主图中文生图提示词。

3. 每一张都能直接复制给生图工具执行。

```Plain Text
1. 生成的每一张主图画面里只能出现产品本体和真实空间场景。

6. 光影要真实自然，优先使用窗边自然光、柔和侧光、晨光、午后光、暖调室内灯光或高级摄影棚软光。

四、信息真实性规则
1. 只能使用图片中可确认的信息和高置信度视觉推断。

1. 只输出“图片标题 + 中文生图提示词”，不要输出解释说明。
2. 每张提示词都必须足够详细，能直接交给生图工具执行。
3. 不要输出英文版提示词。
4. 每张提示词都要写清：产品锁定、画面构图、主体位置、空间场景、光影、镜头、材质质感、道具克制、纯视觉无文字约束、商业摄影质感。
```

操作方式：

1. 把 Gemini 输出的每一张“中文生图提示词”单独复制出来。

2. 每次把家具产品参考图 + 对应主图提示词一起发给生图工具。

5. 某一张不稳定时，优先使用补刀提示词微调，不要直接重写整套。

## 纯视觉主图验收标准

1. 画面没有任何文字：无中文、英文、数字、伪文字、乱码、品牌字样、Logo。

2. 画面没有任何信息布局：无标题、副标题、卖点标签、参数卡、角标、徽章、底部条、图标、箭头、尺寸线、表格。

3. 产品外观一致：品类、结构、比例、颜色、材质、腿部、柜门、抽屉、扶手、靠背、软包、五金等关键细节没有跑偏。

4. 产品是主角：主体完整清晰，不被场景、道具、人物、光影遮挡。

5. 场景真实合理：空间风格和产品一致，道具少而准，不像杂乱样板间。

6. 主图之间有差异：首图、空间、生活方式、材质、尺度、风格收口各有职责。

7. 商业质感足够：光影自然、材质真实、构图高级，适合电商主图轮播。

```Plain Text

```

```Plain Text
请重新强化产品锁定规则：以原始家具产品图作为唯一外观参考，严格保持家具品类、整体轮廓、长宽高比例、颜色、材质纹理、腿部结构、扶手、靠背、桌面、柜门、抽屉、床头、软包、五金件和所有可见结构不变。不得新增原图中不存在的灯带、抽屉、柜门、拉手、升降结构、电动结构、按摩结构、隐藏收纳或装饰线条。
```

```Plain Text
请减少场景和道具的存在感，让家具产品成为第一视觉主角。产品占画面 45% 到 70%，保持完整清晰，背景只保留与产品风格匹配的真实空间层次和少量辅助道具。不要让绿植、装饰画、人物、窗景或软装抢走主体。
```


