# 服饰类主图与详情页生图 SOP

## 适用品类说明

适合：

1. 上衣、衬衫、T 恤、卫衣、外套、羽绒服、西装、针织衫

2. 裤子、半裙、连衣裙、套装、家居服、内搭

3. 鞋靴、包袋、帽子、围巾、腰带等服饰配件

4. 以及相近的电商服饰标品

这份 SOP 默认按“服饰类广泛通用”处理，Gemini 需要根据图片自动判断更偏：

1. 女装

2. 男装

3. 童装

4. 鞋靴

5. 箱包配饰

## 使用前准备

推荐准备：

1. 主体完整、轮廓清晰、尽量没有严重褶皱或遮挡的产品图，最好是3张不同视角的；第二步提示词默认只上传 1 张主视角白底图，其余视角留作局部细节参考。

2. 如果是服装，最好能看清版型、领口、袖型、门襟、下摆、面料纹理

3. 如果是鞋靴，尽量看清鞋头、鞋底、鞋面、鞋帮、五金或拼接关系

4. 如果是包袋配饰，尽量看清开合方式、肩带、五金、包型、容量轮廓

5. 若能补充品牌名、尺码段、面料、季节、人群、价格带会更稳；不补也能先跑保守版

```Plain Text

```

## 第四步：把白底图 + 提示词喂给生图工具

操作方式：

1. 把 Gemini 输出的每一页“中文生图提示词”复制出来

2. 再把产品白底图和对应提示词一起发给批量生图工具 musart ai / 稿定ai / 星流 / lovart，选择 nano banana 2 或 nano banana pro 模型，输出质量：nano banana pro 优于 nano banana 2

3. 主图按`1:1`生成，也有电商平台主图是支持`3:4`的，详情页按 `3:4` 生成

4. 某一页不稳时，优先用补刀提示词微调，而不是直接重写整套

## 这个类目最容易翻车的点

1. 擅自改版型，把宽松做成修身，把直筒做成紧身，把鞋靴包袋改款

2. 过度补全面料、尺码、成分、功能科技，导致信息造假

3. 模特和场景很好看，但产品细节被遮挡，看不清卖什么

4. 为了“时尚感”弱化了电商信息模块，导致图很美但不转化

5. 服装的褶皱、垂感、厚薄感被 AI 改得不真实，直接跑品

6. 把上身场景做得太复杂，反而偏成杂志大片，不像电商图
