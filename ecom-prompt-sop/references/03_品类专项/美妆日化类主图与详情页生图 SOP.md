# 美妆日化类主图与详情页生图 SOP

## 适用品类说明

适合：

1. 口红、粉底、香水、精华、面霜、面膜、唇釉

2. 洗发水、护发素、沐浴露、身体乳、护手霜

3. 美妆护肤日化类包装产品

4. 强调包装质感、色彩氛围、肤感联想、质地表达的产品

不太适合：

1. 纯 3C 数码

2. 强结构工程产品

3. 大型家居用品

## 使用前准备

推荐准备：

1. 主体完整、角度清晰、尽量干净的产品实拍图，最好是3张不同视角的。

2. 若是美妆类，尽量拍到颜色、膏体、瓶身、泵头、盒体等关键细节

3. 若能补充品牌名、色号、功效、价格带，效果更稳；不补也能先跑保守版

## 第一步：实拍图转白底

把产品实拍图发给 AI，并附上下面这段提示词：

```Plain Text
请帮我仔细精修出产品的白底图，希望能保持它原本的样子，不要做出任何外观上的改变，在展示产品的时候，能呈现出最清晰、最完美的视觉效果。背景处理为干净纯白或极浅米白，不要加入多余道具，不要改变瓶身、盖子、膏体、标签、颜色、质感和包装结构，适合后续继续用于美妆日化类主图和详情页生图参考。
```

## 这个类目最容易翻车的点

1. 把包装颜色、色号、膏体颜色改错

2. 擅自补全成分、香调、功效、容量，导致信息造假

3. 过度加花瓣、水珠、丝带，反而遮挡产品主体

4. 只顾高级感，完全没有电商信息模块

5. 把日化做成医药图，或者把美妆做得太像廉价大促图

## 类目专用补刀说明

### 如果主图不够高级

```Plain Text
请把整套主图的视觉气质再往美妆品牌大片方向提升：强化材质氛围、柔光层次、包装细节、精致留白和高定静物语言，但仍然保留清晰的电商信息模块，不要变成只有氛围没有转化信息的杂志图。
```

### 如果详情页不够像美妆

```Plain Text
请把每一页详情页的美妆日化气质再明确一些：增加质地联想、材质语言、色彩氛围、包装细节、成分或护理感信息模块，让页面更像成熟品牌的美妆商详，而不是通用模板页。
```

### 如果产品开始跑品

```Plain Text
请重新强化产品锁定规则：以原始实拍图作为唯一外观参考，严格保持包装结构、颜色、标签、盖体、膏体或液体表现不变，不得新增或替换任何包装细节。
```
