# 老檀木串珠线香类主图与详情页生图 SOP

## 适用品类说明

适合：

1. 老檀木手串、串珠、佛珠、念珠、把玩珠类产品

2. 老檀木线香、卧香、香条、香盒、香插等香道周边

3. 更偏新中式、文玩、香道、东方生活方式气质的产品

4. 木质、香材、器物感强，视觉重点在材质、纹理、色泽、氛围和仪式感的产品

这份 SOP 默认按“文玩香道类广泛通用”处理，`Gemini` 需要根据图片自动判断更偏：

1. 串珠文玩类

2. 线香香道类

3. 串珠 + 香道组合礼品类

4. 香器配件类

不太适合：

1. 明显偏珠宝首饰、贵金属或现代潮饰风格的产品

2. 明显偏食品香薰蜡烛、香氛喷雾、精油、日化香氛的产品

3. 需要强认证、强功效、强参数支撑的专业功能产品

## 使用前准备

推荐准备：

1. 主体完整、轮廓清晰、没有严重遮挡的产品图，最好能看清木纹、珠径、开孔、打磨细节或线香形态

2. 如果是串珠，尽量能看清珠子数量关系、串绳、吊坠、隔珠、流苏或配件

3. 如果是线香，尽量能看清香条形态、粗细、数量关系、包装方式、香插或香盒结构

4. 如果是礼盒套装，尽量看清外包装、内衬、配件、附赠物和摆放关系

5. 若能补充产品名称、规格、珠径、支数、香长、香韵描述、包装清单、赠品、产地或服务信息会更稳；不补也能先跑保守版

推荐补充信息：

1. 产品名称：帮助 `Gemini` 在冷门产品上先建立锚点

2. 规格信息：例如 `8mm / 108 颗 / 21cm / 40 支 / 21cm 香长`

3. 香韵或材质信息：例如“老檀木纹理感”“木质调”“沉稳温润”

4. 服务信息：例如“礼盒装 / 附香插 / 送礼袋 / 售后说明”

5. 如果品牌氛围够了但信息不够，就优先补刀信息布局，不要重做整套气质

## 这个 SOP 最容易翻车的点

1. 把老檀木、木纹、色泽做得太假，像塑料珠或喷漆木

2. 把线香画得像普通木棒、香薰蜡烛或烟草制品

3. 整套画面只有烟雾、茶席和禅意背景，缺少清晰电商信息布局

4. 乱编珠径、颗数、香长、支数、材质等级、香韵、燃烧时长、包装清单

5. 过度宗教化、神秘化或夸大疗愈功效，导致内容风险变高

6. 礼盒、香插、流苏、吊坠、隔珠等细节在不同页面来回变化，导致跑品

## 类目专用补刀说明

### 如果木纹和器物感不够高级

```Plain Text
请进一步强化这套页面里的木质纹理、打磨层次、器物边角和东方静物质感，让老檀木串珠或线香产品看起来更温润、更克制、更高级，但不要做成塑料高光或过度油亮的假木质效果。
```

### 如果氛围够了但信息布局太弱

```Plain Text
请把这套主图 / 详情页做得更像成熟电商设计稿：每一页必须明确写出标题区、副标题区、卖点标签区、参数区、细节放大区、辅助说明区和底部信息条的位置，不能只有茶席、烟雾和静物氛围，没有真正的信息布局。
```

### 如果香道场景过于宗教化

```Plain Text
请把整套画面调整为更偏东方生活方式、新中式书房和茶席静物审美，弱化寺庙、法器、强宗教图腾和神秘化元素，保持克制、高级、可商用的电商气质。
```

### 如果规格和清单表达不稳

```Plain Text
请重新处理规格 / 参数 / 清单页：只保留图片中可确认的信息，无法确认的珠径、颗数、香长、支数、配件或赠品，一律使用“待补充规格位”“待补充清单位”等保守表达，不要编造具体数值。
```
