# 包包类通用主图与详情页生图 SOP

这份 SOP 用于把 `1 张或多张同一包包的真实产品图`，转成一套可执行的：

1. 产品真值卡；
2. 主图与详情页动态规划；
3. 可逐张复制给生图工具的中文提示词；
4. 设计师可直接照做的构图、排版和后期规范；
5. 包类专项验收清单与返修提示词。

本 SOP 采用“固定执行闭环 + 动态图片职责”，不强制所有包包套同一页数或同一顺序。AI 必须根据包型、目标平台、真实卖点、素材完整度和购买顾虑决定图片数量与页面结构。

---

## 一、适用范围

适合：

1. 手提包、托特包、腋下包、单肩包、斜挎包、双肩包；
2. 手拿包、晚宴包、旅行包、公文包、通勤包；
3. 结构相近的小皮具、收纳包和功能包；
4. 淘宝、天猫、京东、抖音、小红书商城等国内电商；
5. 跨境电商、独立站和内容种草渠道；
6. 从商品底图、主图规划、详情页规划到设计师交付的一整套制作。

## 二、不适用情况

以下情况不要直接生成完整商详：

1. 多个不同产品或多个 SKU 混在一起，但没有标明主推款；
2. 产品主体模糊、严重遮挡，无法判断包型、肩带、五金或开合结构；
3. 需要展示精确尺寸、容量、材质、重量、认证或工艺，但没有真实资料；
4. 需要复刻其他品牌的 Logo、文案、花型、独家设计或商品事实；
5. 需要生成销量、排名、价格、优惠、售后或检测结论，但没有商家确认；
6. 需要实际核对某个平台最新首图规则，却没有查询当前平台后台规范。

如果关键结构缺失，先补拍产品图；如果只是信息不完整，可以先输出保守版，用占位符保留版式位置。

---

## 三、核心原则

### 1. 产品图是唯一外观依据

所有主图和详情页都必须严格保持：

1. 包体轮廓、宽高厚比例、软硬挺度；
2. 提手和肩带的数量、连接点、长度、宽度和可拆状态；
3. 包盖、拉链、磁扣、抽绳等开合方式；
4. 五金的颜色、数量、形状、Logo 和装饰位置；
5. 面料观感、纹样位置、拼接、走线、边油和包底结构；
6. 原图中真实可见的内里、隔层、口袋和配件。

可以更换背景、镜头、场景、模特局部和排版，但不能把产品改成另一个款式。

### 2. 用户资料是唯一商品信息依据

图片看不到、用户没有填写的信息，不能靠常识补成确定事实。

禁止编造：

1. 真皮、头层牛皮、真丝、防水、耐磨等材质和性能；
2. 精确尺寸、重量、容量、隔层数量和可装物品；
3. 非遗、手工、工坊、传承人、独立编号、限量和孤品；
4. 认证、检测、销量、排名、价格、优惠、赠品和售后；
5. 原产地、设计师、品牌历史和绝对化承诺。

信息不足时只能：

1. 使用 `【待补充尺寸】`、`【待补充材质】`、`【待补充容量】`、`【待补充服务】` 等占位符；
2. 把具体结论改成外观描述；
3. 删除缺少证据的页面职责。

### 3. 主图和详情页职责不同

1. 主图负责商品识别、吸引点击、快速表达购买理由；
2. 详情页负责解释价值、展示证据、建立信任、消除顾虑；
3. 每张图必须有独立职责，不能只换背景、换姿势或换一句标题；
4. 整组视觉统一，但页面构图、镜头和信息重点必须有变化。

### 4. 默认不出现可识别人脸

允许：

1. 手部、手臂、肩部以下、下巴以下；
2. 背影、侧后方远景和局部上身；
3. 自然手提、肩背、斜挎、腋下夹持等使用动作。

禁止：

1. 清晰眼睛、鼻子、嘴、正脸、侧脸和半张脸；
2. 明星脸、网红脸、真实人物复刻；
3. 人物遮挡包体关键结构；
4. 手指异常、穿模、肩带穿过身体或衣服。

### 5. 默认不生成无关电子设备

包类主图和详情页默认不要出现手机、相机、平板、耳机或带明显品牌特征的电子产品。容量展示优先使用卡夹、钥匙包、纸巾、口红、笔记本等中性物品。

只有用户明确提供真实尺寸、真实装载关系并要求展示时，才可加入指定物品；不得生成品牌型号、屏幕内容、摄像头特征或虚假“可装下”结论。

### 6. 参考资料只负责方法，不负责商品事实

对标店铺、竞品图片和案例资料只可用于提炼：

1. 极简留白；
2. 场景化首屏；
3. 材质和五金特写；
4. 生活方式代入；
5. 品牌故事节奏；
6. 信任证明位置；
7. 参数结构化表达；
8. 购买收口逻辑。

不得继承竞品品牌名、Logo、原文案、产品结构、材质、参数、认证、价格、销量、促销和售后。

---

## 四、使用工具

1. `Gemini / 豆包`：识别产品、建立产品真值卡、规划主图和详情页、输出中文生图提示词；
2. `Lovart / 稿定 AI / 星流 / 三万图 AI`：根据产品图和逐张提示词生成图片；
3. `Photoshop / 稿定设计 / Canva`：精修产品、排版中文、统一字体和完成最终导出；
4. 可选：表格或 Markdown 文档，用于记录真实参数、页面职责和验收结果。

---

## 五、使用前准备

### 1. 产品图片最低要求

建议准备 `3 至 6 张` 同一产品、同一 SKU 的图片：

1. 正面完整图；
2. 侧面或斜侧图；
3. 背面图；
4. 包口和开合结构图；
5. 肩带、提手、五金、走线或纹样细节图；
6. 内里、隔层和容量图。

只有 1 张图也可以先做，但 AI 不能补出看不见的背面、内里或配件。

### 2. 素材角色必须分清

如果同时上传产品图与对标图，必须明确：

1. `产品图`：只负责真实包包外观和商品事实；
2. `对标图`：只负责风格、构图、色彩、光影和信息布局；
3. 最终不能出现对标商品的品牌、文案、结构、卖点或参数；
4. 两类图片不能互换角色。

### 3. 用户输入区

复制下面模板，能填写多少就填写多少。没有的信息留空，不要猜。

```Plain Text
用户输入区：
- 目标平台：
- 输出范围：【主图 + 详情页 / 仅主图 / 仅详情页】
- 输出语言：
- 产品名称：
- 品牌名：
- 包型：
- 主图数量：
- 详情页数量：
- 主图比例：
- 详情页比例：
- 真实材质：
- 真实尺寸：
- 真实重量：
- 真实容量：
- 开合方式：
- 背法：
- 提手/肩带信息：
- 五金信息：
- 内里/隔层信息：
- 核心卖点：
- 目标人群：
- 使用场景：
- 价格带/定位：
- 设计风格：
- 文化/工艺证明：
- 包装信息：
- 真实服务信息：
- 禁止出现：
- 其他要求：
```

### 4. 默认值规则

用户没有填写时按以下逻辑执行：

1. 目标平台：默认按国内货架电商的转化逻辑规划；
2. 输出范围：默认同时输出主图和详情页；
3. 输出语言：默认中文；
4. 主图数量：按商品复杂度、可见卖点和平台轮播需要动态决定；
5. 详情页数量：按购买决策链路、信息复杂度和真实证据动态决定；
6. 主图比例：默认 `1:1`；
7. 详情页比例：默认 `3:4` 单页，最后可拼成长图；
8. 品牌名：未填写时使用 `【品牌名】`，不生成虚构品牌；
9. 参数：未填写且图片不可确认时使用明确占位符；
10. 模特：默认只使用无脸局部模特；
11. 文化与工艺：没有真实证明时关闭；
12. 复杂中文：优先预留排版位置，最终由设计工具补字。

> 平台图片比例、首图文字和人物规则可能更新，实际上架前必须核对目标平台与具体类目的当前要求。

## 六、标准工作流

1. 整理同一产品、同一 SKU 的多角度图片；
2. 填写用户输入区；
3. 必要时先生成干净产品底图；
4. 把产品图、用户输入区和“主图详情页总控提示词”一起发给 Gemini / 豆包；
5. 先检查产品真值卡和页面规划，再开始生图；
6. 每次只生成 1 张主图或 1 页详情页；
7. 发现跑品先修产品，发现文字问题优先后期排版；
8. 设计师统一字体、颜色、信息卡、图标和页面节奏；
9. 按包类专项验收表逐张检查；
10. 通过后再导出主图组和详情页长图。

## 七、第一步：生成干净产品底图

把同一包包的产品图发给 AI，并复制下面提示词。

```Plain Text
请把用户上传的包包产品图精修成适合后续电商主图和详情页生成的干净产品底图。

必须把上传图片作为唯一产品外观依据，严格保持包包原貌：
1. 保持包型、轮廓、宽高厚比例、软硬挺度和包底结构不变；
2. 保持提手和肩带的数量、连接点、长度、宽度、调节结构和可拆卸状态不变；
3. 保持包盖、拉链、磁扣、抽绳等开合结构不变；
4. 保持五金颜色、数量、形状、Logo、拉链头、扣件和装饰位置不变；
5. 保持颜色、材质观感、纹样位置、拼接、走线、边油和所有可见细节不变；
6. 原图看不见的背面、内里、隔层和配件不要补画。

可以处理：
1. 去除原背景和无关杂物；
2. 修正轻微曝光、白平衡和脏点；
3. 提升边缘清晰度和材质细节；
4. 补足自然接触阴影；
5. 背景改为纯白或极浅暖灰。

禁止：
1. 改款、改色、改材质、改变包体比例；
2. 增加或删除肩带、提手、五金、Logo、口袋、拉链和装饰；
3. 把柔软包体变硬挺，或把硬挺包体变塌软；
4. 美化成不存在的昂贵材质；
5. 生成文字、价格、标签、平台 Logo、水印和促销元素。

输出一张主体完整、边缘清晰、颜色准确、结构真实、适合后续作为唯一外观参考的包包产品底图。
```

## 八、第二步：AI 直出主图与详情页规划及逐张提示词

### 使用方式

1. 上传同一包包的产品图；
2. 把已填写的用户输入区放在下面提示词最前面；
3. 将整段提示词发给 Gemini / 豆包；
4. AI 先输出产品真值卡和规划表，再输出逐张生图提示词；
5. 如果只要主图或只要详情页，修改“输出范围”即可。

### 主图详情页总控提示词

```Plain Text
你是一名资深电商视觉总监、包袋商品摄影导演、详情页策划师、商业平面设计师和 AI 生图提示词工程师。

我会上传 1 张或多张同一包包、同一 SKU 的真实产品图，并提供用户输入区。你的任务不是套固定模板，也不是直接生成一张普通海报，而是完成一套“产品真值卡 + 动态页面规划 + 逐张中文生图提示词”，同时让结果可以交给 AI 生图工具和电商设计师执行。

【用户输入区：以下为字段清单；实际内容以上方粘贴的已填输入区为准，未填字段按规则保守自动生成】
- 目标平台：
- 输出范围：【主图 + 详情页 / 仅主图 / 仅详情页】
- 输出语言：
- 产品名称：
- 品牌名：
- 包型：
- 主图数量：
- 详情页数量：
- 主图比例：
- 详情页比例：
- 真实材质：
- 真实尺寸：
- 真实重量：
- 真实容量：
- 开合方式：
- 背法：
- 提手/肩带信息：
- 五金信息：
- 内里/隔层信息：
- 核心卖点：
- 目标人群：
- 使用场景：
- 价格带/定位：
- 设计风格：
- 文化/工艺证明：
- 包装信息：
- 真实服务信息：
- 禁止出现：
- 其他要求：

请严格按以下顺序执行。

一、先建立产品真值卡

把所有信息分成 4 类：
1. 图片可见事实：只记录图中能够看清的包型、结构、颜色、肩带、提手、开合、五金、纹样、走线、边油、内里和配件；
2. 用户明确提供事实：只记录用户输入区填写的信息；
3. 不可确认信息：列出图片和用户输入都无法确认的材质、尺寸、重量、容量、认证、工艺、服务等；
4. 全流程禁止改动项：列出后续每张图都必须锁定的产品特征。

图片事实和用户事实冲突时，明确标记冲突，不要自行选择一个当成真相。

二、判断平台与视觉路线

1. 根据目标平台判断首图是否需要纯净商品展示、是否可使用文字、场景、人物和信息模块；
2. 如果是国内货架电商，重点兼顾商品识别、卖点信息和点击理由；
3. 如果是内容电商或种草渠道，强化真实使用场景、搭配关系和生活方式，但不能弱化商品；
4. 如果是跨境平台，首图采用保守合规方案，具体平台类目规则需要用户上架前再次核对；
5. 根据包型、颜色、材质观感、纹样复杂度和价格定位，选择最适合的视觉路线；
6. 可选路线包括极简轻奢、都市通勤、自然松弛、潮流街头、复古艺术、东方人文、旅行功能等；
7. 不得所有包包都套用黑金、奶油、科技蓝或新中式。

三、动态规划主图

主图数量读取用户输入；未填写时，根据产品复杂度、真实卖点、可见信息量和平台轮播需要自行决定。如果用户填写的数量超过真实内容能够承载的范围，先给出“安全建议数量”和原因，不能用重复页面或虚构信息强行凑数。

主图职责任务库不是固定顺序，也不要求全部使用。请按当前产品选择最有价值的职责：
1. 商品识别与首屏风格定调；
2. 核心购买理由或差异点；
3. 真实手提、肩背、斜挎、腋下等背法；
4. 上身尺度与穿搭关系；
5. 通勤、约会、旅行、晚宴、休闲等场景适配；
6. 包型轮廓、开合结构与使用便利；
7. 材质观感、纹样、拼接、走线、边油和五金细节；
8. 真实容量、内部结构和取放关系；
9. 多色或多 SKU 关系；
10. 真实包装、服务、信任与购买收口；
11. 有真实证明时的文化、工艺和品牌故事；
12. 目标平台要求的纯净首图或规格展示。

每张主图只能承担一个核心职责，可以有辅助信息，但不能重复换背景凑数量。

四、动态规划详情页

详情页数量读取用户输入；未填写时，根据购买决策链路、商品复杂度、真实证据和转化需要自行决定。如果用户填写的数量超过真实内容能够承载的范围，先给出“安全建议数量”和缺失证据，不能靠重复页面或虚构内容凑数。

详情页职责任务库不是固定顺序，也不要求全部使用：
1. 首屏价值与品牌气质；
2. 目标人群和生活方式代入；
3. 包型设计、轮廓、开合方式和背负体验；
4. 提手、肩带、连接点和多背法；
5. 材质观感、纹样、拼接、走线、边油和五金；
6. 容量、分区、尺寸、重量和上身比例；
7. 通勤、约会、旅行、晚宴等搭配建议；
8. 真实工艺、文化、工坊、证书或品牌证明；
9. 多色、多 SKU 或系列关系；
10. 规格、包装、保养、服务和信任收尾。

详情页必须形成“吸引兴趣 → 解释价值 → 展示证据 → 建立代入 → 消除顾虑 → 推动下单”的阅读链路，但不要为了凑流程加入没有真实资料的页面。

五、产品锁定硬规则

每一张主图和每一页详情页的中文生图提示词，都必须以这句话开头：
“以用户上传的包包产品图作为唯一外观参考，严格保持产品真实原貌。”

随后重复当前产品最关键的外观锁定描述，包括：
1. 包型、轮廓、宽高厚比例和软硬挺度；
2. 提手和肩带数量、连接点、长度、宽度、调节与可拆状态；
3. 包盖、拉链、磁扣、抽绳等开合结构；
4. 五金颜色、数量、形状、Logo 和装饰位置；
5. 颜色、材质观感、纹样位置、拼接、走线、边油和包底；
6. 原图真实可见的内里、隔层、口袋和配件。

不得新增、删除、镜像或移动产品结构。看不见的背面、内里和配件只能保守处理，不能补全。

六、信息真实性硬规则

1. 只能使用图片可见事实和用户明确提供的信息；
2. 不得编造材质、尺寸、重量、容量、性能、认证、工艺、销量、排名、价格、优惠、赠品和售后；
3. 不可确认的信息使用【待补充尺寸】【待补充材质】【待补充容量】【待补充服务】等占位符；
4. 如果某一页面没有真实证据支撑，删除该页面职责或改为纯外观表达；
5. 不得出现任何对标品牌名、Logo、原文案、竞品参数和竞品商品特征；
6. 文化与手作模块只有在用户提供真实工坊、证书、传承人、编号或工艺资料时启用；
7. 禁止使用“全球唯一、顶级、第一、百分百、绝对、防水、永不褪色”等无证据绝对化表达。

七、人物、容量与场景规则

1. 默认禁止可识别人脸，只允许手部、手臂、肩部以下、下巴以下、背影和远景；
2. 人物动作必须符合包包真实背法，肩带和提手不能穿模、悬浮或连接错误；
3. 包体不能被手臂、衣物、头发或道具遮挡关键结构；
4. 容量展示必须符合真实尺寸和内部结构，物品比例正确，不能为了显大缩小物品；
5. 默认不出现手机、相机、平板、耳机或其他无关电子设备；
6. 只有用户明确提供真实尺寸、真实装载关系并要求展示时，才可加入指定容量物品；
7. 场景和道具必须服务包包的定位与使用关系，不得喧宾夺主或暗示不存在的功能；
8. 同一张图只表达一个核心场景，整组可按页面职责切换场景，但色彩、字体、光影和设计系统要统一。

八、主图视觉与信息规则

1. 主图比例读取用户输入；未填写时默认 1:1；
2. 产品必须一眼可识别，首图主体通常占画面 55% 到 75%，具体按平台和构图调整；
3. 细节页可用局部放大，但要保留完整产品或位置关系；
4. 国内信息型主图可以包含品牌条、主标题、副标题、卖点标签、细节标注和底部信息条；
5. 跨境或平台纯净首图采用保守方案，不强行加入文字、模特、道具或装饰；
6. 纹样丰富、装饰复杂的包，优先使用克制背景、低饱和配色和充足留白；
7. 素面包可以增加空间材质、光影层次和结构性构图；
8. 画面不能只有漂亮模特和场景，必须让商品和购买理由清晰可见。

九、详情页视觉与信息规则

1. 详情页比例读取用户输入；未填写时默认 3:4 单页；
2. 每页只解决一个核心问题，用 3 到 5 个信息区块支撑；
3. 页面必须像成熟包袋品牌的完成态商详，不能只是产品居中加一行标题；
4. 整套统一主色、辅助色、字体气质、信息卡、图标、线条、光影和后期质感；
5. 每页写清主标题、副标题、卖点短句、说明文字和占位参数；
6. 每页写清文字位置、层级、对齐、字距、行距、留白和安全边距；
7. 复杂中文或精确参数优先预留排版区域，最后由设计工具补字；
8. 纹样、五金、走线和边油特写必须保持真实位置与材质，不得为了“高级感”重新设计产品。

十、每条中文生图提示词必须包含

1. 产品外观锁定描述；
```

## 九、主图职责任务库

这是一组可选职责，不是固定顺序。AI 和设计师应根据当前包包选择最有价值的页面。

### 1. 商品识别首图

适合解决：

1. 用户第一眼看不清卖什么；
2. 需要快速建立包型、颜色和风格定位；
3. 需要平台纯净首图或品牌主视觉。

执行重点：

1. 产品大比例、轮廓完整；
2. 开合、肩带和五金不过度遮挡；
3. 背景服务产品，不抢纹样和材质；
4. 如果平台要求纯净首图，删除文字、人物和无关道具。

### 2. 核心购买理由图

适合表达：

1. 独特包型；
2. 多背法；
3. 轻便、收纳、开合便利等有真实资料支撑的利益点；
4. 纹样、拼接或设计细节。

禁止：

1. 用空泛“高级、奢华、顶级”代替真实理由；
2. 把视觉印象写成确定材质、性能或工艺。

### 3. 上身背法与尺度图

适合表达：

1. 手提、单肩、斜挎、腋下、双肩；
2. 包体与人体的真实比例；
3. 通勤、约会、旅行等搭配关系。

执行重点：

1. 只展示产品真实支持的背法；
2. 肩带连接点和长度必须正确；
3. 默认无脸模特；
4. 服装选择低纹理、低饱和，不抢包包；
5. 不用人物姿势掩盖包体结构。

### 4. 场景与生活方式图

场景可按包型选择：

1. 通勤：办公室、城市街区、咖啡馆、交通枢纽；
2. 日常：书店、花店、餐厅、周末街区；
3. 旅行：酒店、车站、行李整理区；
4. 晚宴：画廊、宴会厅、简洁室内；
5. 东方人文：茶室、展览、现代东方空间；
6. 户外功能：真实适用的步行、短途出行和自然场景。

每张图只保留一个核心场景。

### 5. 材质、纹样和五金细节图

适合展示：

1. 材质表面观感；
2. 纹样、拼接、走线、边油；
3. 拉链、扣件、装饰和 Logo；
4. 提手、肩带和连接点。

只能描述可见观感。没有资料时写“细腻纹理”“柔和光泽”“挺括外观”，不能直接写“头层牛皮”“真丝”“纯手工”。

### 6. 容量与内部结构图

启用条件：

1. 有真实尺寸或实拍容量图；
2. 能看清包口、隔层、内袋和开合；
3. 装载物品与包体尺度关系可信。

禁止：

1. 缩小物品制造超大容量；
2. 增加原图没有的隔层和口袋；
3. 把关闭状态的包直接想象成完整内部剖面；
4. 用无关电子设备填充画面。

### 7. 多色与多 SKU 图

启用条件：

1. 用户明确上传多个真实 SKU；
2. 每个 SKU 的颜色、纹样和结构都有清晰依据；
3. 已明确主推 SKU 和展示顺序。

禁止根据一张图自动换色，也不能把不同 SKU 的五金、肩带或纹样混合。

### 8. 文化、工艺与品牌故事图

只有存在真实材料时启用：

1. 工坊或生产现场；
2. 真实证书和可核对标识；
3. 真实工艺过程；
4. 真实传承人、设计师或品牌历史；
5. 真实编号、限量或定制规则。

如果只有文化氛围，没有证据，只能做视觉风格，不能写事实性背书。

### 9. 包装、服务与购买收口图

只使用用户确认的信息：

1. 包装清单；
2. 防尘袋、礼盒、吊牌和配件；
3. 保养说明；
4. 发货、退换、维修和客服；
5. 真实活动或赠品。

未知内容统一用占位符，不能使用“顺丰包邮”“七天无理由”“官方质保”等默认文案。

## 十、详情页购买决策链路

详情页不是主图放大版，应围绕购买顾虑动态组织。

### 第一阶段：吸引兴趣

目标：

1. 一眼理解包型与定位；
2. 建立目标人群和生活方式；
3. 给出值得继续看的核心理由。

可选页面：

1. 首屏价值页；
2. 风格与人群页；
3. 场景导入页。

### 第二阶段：解释价值

目标：

1. 讲清设计、结构、背法和使用便利；
2. 展示材质观感、纹样、五金和细节；
3. 把抽象“好看”转成可见证据。

可选页面：

1. 包型设计页；
2. 多背法页；
3. 材质与纹样页；
4. 五金与工艺细节页；
5. 开合与使用页。

### 第三阶段：建立代入

目标：

1. 让用户理解上身尺度；
2. 看见通勤、约会、旅行等真实使用关系；
3. 理解容量、取放和搭配效率。

可选页面：

1. 上身尺度页；
2. 多场景搭配页；
3. 容量与分区页；
4. 装载和取放页。

### 第四阶段：消除顾虑

目标：

1. 给出真实规格；
2. 展示包装、保养和服务；
3. 用真实证据完成信任收口。

可选页面：

1. 尺寸、重量和参数页；
2. 包装清单页；
3. 保养说明页；
4. 文化、工艺或品牌证明页；
5. 服务与购买收口页。

如果没有证据，不得为了形成完整链路而补造事实。

## 十一、设计师执行规范

### 1. 先建立整组视觉 DNA

设计师在排版前先确定：

1. 主色；
2. 辅助色；
3. 强调色；
4. 标题字体气质；
5. 正文字体气质；
6. 信息卡与图标风格；
7. 背景材质；
8. 主光方向和色温；
9. 图片颗粒、锐度和对比度；
10. 页面留白节奏。

整套字体建议不超过 `3` 种，核心颜色建议不超过 `3` 个角色。这里的“3”指设计系统角色，不包含商品自身的多种颜色。

### 2. 根据包包复杂度控制背景

纹样丰富、刺绣复杂、五金装饰较多的包：

1. 背景使用浅米、暖灰、深褐、墨绿等克制色；
2. 道具少而精；
3. 增加留白；
4. 让光影突出纹理，不再增加复杂花纹。

素面、极简、纯色包：

1. 可增加石材、木材、金属、玻璃、布艺等空间材质；
2. 可用几何光影和非对称构图增加层次；
3. 仍然不能用背景代替产品卖点。

### 3. 构图规范

1. 首图主体通常占画面 `55% 至 75%`，以平台和包型为准；
2. 场景图主体通常占 `35% 至 60%`，但不能失去商品识别；
3. 细节页允许局部放大，同时保留完整包体或位置关系；
4. 人物页先保证肩带、提手和包体结构完整；
5. 道具与包体保持真实接触阴影和尺度；
6. 页面预留文字安全区，不把文字压在纹样、Logo 和五金上。

### 4. 信息排版规范

每张信息型主图或详情页至少规划：

1. 主标题；
2. 副标题；
3. 1 至 4 个卖点标签或说明模块；
4. 必要的细节标注、参数占位或底部信息条。

文字层级：

1. 主标题短而具体，优先 `4 至 12` 个字；
2. 副标题负责解释，优先 `10 至 24` 个字；
3. 标签优先 `4 至 10` 个字；
4. 精确参数和长说明由后期排版工具完成；
5. 不用大量英文伪字、乱码和无意义装饰字填版面。

### 5. 图文分层执行

推荐顺序：

1. 生成无文字或少文字的产品场景底图；
2. 检查产品是否跑品；
3. 修正商品、人物和道具关系；
4. 在设计工具中加入准确中文；
5. 统一字体、字号、间距、图标和信息卡；
6. 逐页检查安全边距和移动端可读性；
7. 最后导出平台尺寸。

### 6. 平台适配分支

国内货架电商：

1. 主图更强调商品识别、卖点和快速阅读；
2. 详情页信息密度可以更高；
3. 促销和服务只能使用真实信息。

内容电商与种草渠道：

1. 强化上身、场景、搭配和生活方式；
2. 保留商品清晰度，不能变成只有氛围的杂志图；
3. 文字更少、更像真实内容封面。

跨境平台：

1. 首图采用保守纯净商品展示；
2. 轮播图再承担场景、结构、尺寸、容量和细节；
3. 输出语言按用户输入；
4. 实际上架前重新核对目标平台与类目当前规则。

## 十二、逐张生图操作

1. 从 AI 输出中复制一张图的完整中文生图提示词；
2. 同时上传产品底图和必要的结构/细节图；
3. 每次只生成 1 张图；
4. 先验收产品，再验收场景和文字；
5. 商品错误时不要继续生成下一张；
6. 商品正确但文字错误时，保留图像并在设计工具中重排；
7. 完成全部单页后，再统一色彩和拼接详情页长图。

- [ ] 不可见背面、内里和配件没有被凭空补全；

- [ ] 装载物品与包体比例可信；
- [ ] 没有缩小物品制造大容量；
- [ ] 隔层、内袋和开合方向与原图一致；
- [ ] 没有加入无关手机、相机或带品牌特征的电子设备；
- [ ] 未确认信息使用占位符或删除页面。

### D. 视觉与转化

- [ ] 首图一眼看清卖什么；
- [ ] 每张主图有不同职责；
- [ ] 详情页形成清晰购买决策链路；
- [ ] 整套色彩、字体、信息卡、图标和光影统一；
- [ ] 纹样丰富的包没有被复杂背景淹没；
- [ ] 素面包的背景层次没有抢过商品；
- [ ] 主标题、副标题和标签清晰可读；
- [ ] 没有乱码、错别字、伪英文和无意义装饰字；
- [ ] 页面安全边距和移动端阅读正常。

### E. 商业与合规

- [ ] 没有编造材质、尺寸、重量、容量和性能；
- [ ] 没有编造认证、工艺、销量、排名和绝对化承诺；
- [ ] 没有编造价格、优惠、赠品、物流和售后；
- [ ] 没有泄漏竞品品牌、文案、参数和产品事实；
- [ ] 文化与手作背书有真实资料；
- [ ] 平台首图和图片比例已按当前类目规则核对。

## 十四、常用返修提示词

### 1. 包型或比例跑品

```Plain Text
请基于上一版重新生成，只修正产品外观。必须以用户上传的包包产品图作为唯一依据，恢复真实包型、轮廓、宽高厚比例、软硬挺度和包底结构。删除上一版擅自改变的鼓包、塌陷、拉长、压扁、加厚或缩薄效果。场景、光影和版式可以保留，但不能改变包包本身。
```

### 2. 肩带、提手或开合结构错误

```Plain Text
请重新锁定包包的提手、肩带和开合结构。严格保持提手和肩带的真实数量、连接点、长度、宽度、调节件和可拆状态不变；保持包盖、拉链、磁扣或抽绳位置不变。删除所有原图不存在的肩带、扣件和连接环，不得改变真实背法。
```

### 3. 五金错误

```Plain Text
请只修正包包五金，保留其余画面。五金颜色、数量、形状、大小、表面光泽、Logo、拉链头、扣件和装饰位置必须与用户上传产品图一致。不要把金色改成银色，不要镜像 Logo，不要新增挂件、铆钉、锁扣或金属环。
```

### 4. 纹样漂移或材质被替换

```Plain Text
请恢复产品真实纹样和材质观感。纹样的位置、方向、大小、连续关系、拼接边界和颜色必须与用户上传图一致；走线、边油和表面纹理保持真实。不要重新设计花纹，不要把织物改成皮革、把皮革改成塑料，也不要凭空加入刺绣、压纹或金属装饰。
```

### 5. 容量虚构或物品比例错误

```Plain Text
请删除没有真实尺寸和实拍依据的容量结论。恢复包体、包口和内部空间的真实比例，所有装载物品保持正常尺度，不得缩小物品制造大容量。只展示用户确认可以容纳的物品；无法确认的位置改为【待补充容量】，或把本页改成外观与开合展示。
```

### 6. 内里和隔层被凭空补全

```Plain Text
请删除上一版凭空生成的内袋、隔层、拉链袋、卡位和衬里结构。只保留用户上传图片中真实可见的内部结构；看不见的位置使用保守暗部或局部裁切，不做完整剖面，不推断隔层数量和内里材质。
```

### 7. 人物背法、手指或穿模错误

```Plain Text
请修正人物与包包的真实接触关系。只使用产品真实支持的背法，肩带和提手自然承重，不穿过身体、衣服或头发；手指数量和握持姿势正常，包体不悬浮、不穿模。人物只展示手部、手臂、肩部以下、下巴以下或背影，禁止出现可识别人脸，同时确保包包关键结构无遮挡。
```

### 8. 页面重复、只换背景

```Plain Text
请重新规划当前整组图片的页面职责。每张主图和每页详情页必须解决不同问题，不能只更换背景、模特姿势或标题。围绕商品识别、核心购买理由、真实背法、场景搭配、包型结构、材质五金、容量内里、真实信任和购买收口进行取舍；删除重复页面，不需要凑固定数量。
```

### 9. 文字乱码或文案造假

```Plain Text
请保留产品、构图、场景和光影，只修正文字与信息。删除乱码、错别字、伪英文、无意义装饰字，以及无法从产品图或用户输入确认的材质、尺寸、容量、认证、销量、价格、优惠和服务。未知信息使用明确占位符。复杂中文请预留干净排版区域，后续由设计工具补字。
```

### 10. 整组视觉不统一

```Plain Text
请统一整套主图和详情页的视觉系统，保留每页不同职责。统一主色、辅助色、字体气质、标题层级、信息卡、图标、线条、主光方向、色温、阴影和后期质感；不要把每页做成不同品牌。纹样复杂的包保持克制背景和大留白，素面包可以增加空间材质，但都必须让产品成为第一视觉主体。
```

### 11. 模特或场景抢产品

```Plain Text
请降低人物、服装、道具和背景的视觉权重，增大包包主体，完整展示包型、肩带、五金和关键细节。人物只用于说明背法、尺度和搭配，不得遮挡产品；背景减少复杂纹理和高饱和颜色，主光优先照亮包包。
```

### 12. 对标信息泄漏

```Plain Text
请删除画面和文案中所有对标品牌、竞品 Logo、原标题、原卖点、原参数、原价格、原促销、原花型和原商品结构。只保留抽象的构图、色彩、光影、留白和信息层级；产品外观与商品事实完全以用户上传的包包和用户输入区为准。
```

## 十六、最终合格标准

一套合格的包包主图和详情页必须满足：

1. 任何一张图单独看，都能清楚识别包型和商品；
2. 包体、肩带、提手、开合、五金、纹样和结构始终与原图一致；
3. 主图有点击理由，详情页有完整购买决策链路；
4. 页面职责动态适配当前产品，不靠固定模板和重复换背景；
5. 真实信息与占位信息分开，不编造商业事实；
6. 人物背法、容量物品和场景关系真实；
7. 默认没有可识别人脸和无关电子设备；
8. 参考资料只贡献设计方法，没有竞品事实泄漏；
9. 整套视觉统一，同时每页构图和信息重点不同；
10. 设计师能直接继续排版、复核和导出；
11. 平台规则、精确参数和服务信息已在实际上架前核对；
12. 每张图都通过包类专项验收清单。

## 十七、参考资料提炼边界

本 SOP 从参考图集中只提炼以下通用方法：

1. 首屏通过场景和包型快速定调；
2. 纹样复杂的产品需要克制背景与留白；
3. 高价值商品需要真实工艺、材料和品牌证据；
4. 详情页按首屏、价值解释、场景代入、参数结构化和信任收口推进；
5. 材质、纹样和五金需要真实光影与局部特写；
6. 参数、包装和服务信息应结构化呈现；
7. 设计感必须服务商品识别和购买转化。

参考资料中的具体品牌、价位、材质、非遗身份、工艺、容量、优惠、定制、销量和售后，均未被视为通用包包事实。
