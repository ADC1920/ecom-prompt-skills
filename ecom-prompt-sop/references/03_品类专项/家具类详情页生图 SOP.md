# 家具类详情页生图 SOP

## 适用品类说明

适合：

1. 沙发、床、床垫、餐桌、茶几、电视柜、书桌、椅子、衣柜、鞋柜、斗柜、置物架等常见家具。

2. 实木、板式、岩板、金属、皮革、布艺、藤编、玻璃、软包等有明确材质表达的家具。

3. 强调空间搭配、尺寸适配、收纳结构、坐感/躺感/承重感、风格氛围和家居生活方式的产品。

4. 适合淘宝、天猫、京东、抖音、小红书商城等电商平台的竖版详情页生成。

不太适合：

1. 纯家纺、纯装饰画、纯灯具、纯厨卫五金等非家具主体产品。

2. 需要复杂安装工程或定制量尺报价的全屋定制项目。

3. 无法确认结构、材质、尺寸关系的模糊图片。

## 使用前准备

推荐准备：

1. 至少 1 张主体完整、角度清晰、无严重遮挡的家具实拍图或白底图。

2. 最好补充 2 到 4 张辅助图：正面、侧面、局部材质、打开/收纳结构、实际空间摆放图。

3. 能补充的信息越多越稳：品牌名、型号、尺寸、材质、颜色、风格、适用空间、承重、安装方式、包装清单、售后服务。

4. 如果缺少参数，不要让 AI 编造，统一使用“待补充尺寸位”“待补充材质位”“待补充承重位”等占位表达。

## 第一步：实拍图转干净产品底图

把多张家具产品图发给 三万图AI，选择多配一模式，并附上下面这段提示词：

```Plain Text
请帮我把这张家具产品图精修成干净、真实、适合后续电商详情页生图参考的产品底图。

要求：
1. 保持家具原本的品类、轮廓、比例、结构、颜色、材质纹理、五金细节、软包形态、腿部结构、抽屉/柜门/扶手/靠背/桌面/椅背等关键部位不变。
2. 背景处理为干净纯白、浅灰白或极简室内底色，不要加入多余道具，不要改变产品真实外观。
3. 如果原图有木纹、布纹、皮纹、岩板纹、金属反光、玻璃边缘、藤编纹理，请尽量保留清晰。
4. 不要擅自新增产品没有的功能结构，例如隐藏抽屉、可升降装置、灯带、按摩功能、电动结构、额外五金件。
5. 输出一张主体完整、边缘清晰、光影自然、适合作为后续家具详情页统一外观参考的产品图。
```

## 第二步：Gemini 直出家具类详情页整套生图提示词

### 作用

通过 `1 到 5 张` 家具产品底图 + 下方总控提示词，让 Gemini 一次性输出：

1. `8` 页标准详情页中文生图提示词。

2. `2` 页可选增强页中文生图提示词。

3. 每一页都能直接复制给生图工具执行。

### 总控提示词

```Plain Text
你现在是一名拥有千万级 GMV 视觉操盘经验的顶级电商详情页策划、家具类目视觉总监、商业平面设计师和 AI 生图提示词导演。

我会上传 1 到 5 张家具产品图片，可能只有 1 张产品实拍图，也可能包含正面、侧面、局部材质、使用场景或结构图。你的任务不是做普通说明页，而是基于这些图片，直接产出一整套“高设计感、高信息密度、真实可商用、适合国内电商平台”的家具类详情页中文生图提示词。

请在后台静默完成以下动作，不要输出分析过程：
1. 识别家具属于哪一类：沙发、床、床垫、餐桌、茶几、电视柜、书桌、椅子、衣柜、鞋柜、斗柜、置物架或其他家具。
2. 判断产品主要风格：现代简约、奶油风、原木风、意式轻奢、北欧风、侘寂风、新中式、复古风、工业风、儿童房风格或其他风格。
3. 提炼一段“产品外观锁定描述”，后续每一页都必须复用，确保产品不跑品。
4. 从图片可确认信息里提炼可视化卖点，例如材质、结构、尺寸关系、收纳能力、空间适配、坐感/躺感、承托感、稳定感、清洁便利、安装便利、风格搭配。
5. 输出 8 页标准详情页 + 2 页可选增强页的中文生图提示词。

请严格遵守以下规则：

一、产品锁定规则
1. 每一页提示词都必须以“以原始家具产品图作为唯一外观参考，严格复刻产品原貌”作为开头约束。
2. 必须严格保持家具品类、整体轮廓、长宽高比例、结构关系、颜色、材质纹理、表面工艺、腿部结构、扶手/靠背/桌面/柜门/抽屉/床头/软包/五金件等关键外观不变。
3. 不得新增原图中不存在的抽屉、柜门、灯带、电动结构、升降结构、按摩结构、隐藏收纳、拉手、脚轮、五金件、装饰线条或品牌 Logo。
4. 允许切换镜头、空间、光影和陈列方式，但不能把产品改成另一种款式，不能改变真实材质和比例。

二、信息真实性规则
1. 只能使用图片中可确认的信息和高置信度推断。
2. 看不清或无法确认的尺寸、材质等级、承重、环保等级、甲醛标准、木材种类、面料成分、皮革等级、五金品牌、产地、质保年限，严禁编造。
3. 如果页面必须展示参数，但信息不足，只能使用“待补充尺寸位”“待补充材质位”“待补充承重位”“待补充规格位”“待补充安装信息位”等占位。
4. 卖点要写成用户利益点，但不得虚构产品做不到的功能。
5. 禁止使用“全网最低”“销量第一”“0甲醛”“100%环保”“永久不坏”等无法确认或违规夸张表述。

三、家具详情页设计规则
1. 默认适配竖版 3:4 电商详情页，画面要像成熟家具品牌的完整商详设计稿，不要做成单张海报或简单场景图。
2. 家具类详情页必须突出空间感、尺度感、材质感、生活方式和购买决策信息。
3. 允许使用真实室内空间、局部特写、结构拆解、尺寸标注、材质样板、参数卡、场景标签、搭配建议、对比矩阵、安装/清洁步骤等视觉语言。
4. 每页至少形成 3 到 5 个信息区块，信息密度通过模块化排版实现，不要靠长段文字堆满。
5. 产品必须始终是主角，道具和空间只能服务产品，不能喧宾夺主。
6. 空间风格要和产品一致：原木家具配自然温润空间，轻奢家具配克制高级空间，儿童家具配明亮安全空间，办公家具配理性效率空间。

四、文字与排版规则
1. 每页都必须明确写出主标题、副标题、卖点短句、信息模块内容。
2. 每页都必须写清文字位置、版式结构、字体气质、字号层级、对齐方式、颜色关系和留白要求。
3. 中文文字必须清晰、规范、可读，不要生成乱码、错别字、英文伪字或无意义装饰字。
4. 主标题建议 6 到 14 个字，副标题建议 10 到 24 个字，卖点短句建议 3 到 5 条，每条 4 到 10 个字。
5. 如果没有明确品牌名，统一使用“自定义”作为默认品牌名。

五、输出要求
1. 只输出“页面标题 + 中文生图提示词”，不要输出解释说明。
2. 每页提示词都必须足够详细，能直接交给生图工具执行。
3. 不要输出英文版提示词。
4. 每页都要写清：产品锁定、画面构图、主体位置、空间场景、光影、标题内容、卖点标签、信息模块、字体气质、对齐方式、商业质感。
```

## 第三步：把提示词交给生图工具批量生成

操作方式：

1. 把 Gemini 输出的每一页“中文生图提示词”单独复制出来。

2. 每次把家具产品参考图 + 对应页面提示词一起发给三万图AI，选择拆页模式。

3. 详情页默认按 `3:4` 生成，如果平台需要长图，可选其他比例。

4. 如果产品结构复杂，建议每一页都附上同一张“最清晰产品底图”，细节页再额外附材质或结构局部图。

5. 某一页不稳定时，优先使用补刀提示词微调，不要直接重写整套。

## 家具详情页标准页面结构

1. 首屏海报页：先让用户确认品类、风格、空间和核心利益。

2. 场景导入页：让用户想象这件家具放在自己家里的样子。

3. 核心卖点页 1：讲最强购买理由，例如舒适、承托、收纳、稳定、节省空间。

4. 核心卖点页 2：讲多个利益点，形成决策补充。

5. 材质工艺页：证明质感和细节，不只靠氛围。

6. 尺寸结构页：解决能不能放、能不能用、是否适配的问题。

7. 搭配生活方式页：强化风格和使用想象。

8. 参数收尾页：收拢购买理由，给出规格和服务信息。

## 这个类目最容易翻车的点

1. 把家具比例改错，例如沙发变短、桌腿变粗、柜门数量变化、床头高度变化。

2. 擅自编造尺寸、承重、环保等级、木材种类、皮革等级、五金品牌。

3. 为了高级感把产品放得太小，用户看不清真实结构。

4. 空间场景很漂亮，但产品主体不突出，详情页变成家装效果图。

5. 材质乱改，实木变岩板，布艺变皮革，金属变塑料，颜色也跑偏。

6. 只有氛围图，没有尺寸、结构、参数、材质、使用场景等购买决策信息。

7. 使用过度夸张文案，例如“0甲醛”“永久不变形”“承重千斤”，导致合规风险。

## 类目专用补刀提示词

### 如果产品开始跑品

```Plain Text
请重新强化产品锁定规则：以原始家具产品图作为唯一外观参考，严格保持家具品类、整体轮廓、长宽高比例、颜色、材质纹理、腿部结构、扶手、靠背、桌面、柜门、抽屉、床头、软包、五金件和所有可见结构不变。不得新增原图中不存在的灯带、抽屉、柜门、拉手、升降结构、电动结构、按摩结构、隐藏收纳或装饰线条。
```

### 如果详情页太像家装效果图

```Plain Text
请把页面从“室内效果图”调整为“成熟家具电商详情页”。保留真实空间感，但必须增加清晰的电商信息模块，包括主标题、副标题、卖点标签、材质说明、尺寸/结构信息区、参数卡、购买理由和底部信任条。产品主体必须占据视觉中心，不能被空间和道具抢走。
```

### 如果信息密度不够

```Plain Text
请提高每一页详情页的信息密度，但不要增加长段文字。通过模块化信息区实现：材质卡、尺寸卡、结构标注、使用场景标签、对比模块、参数区、安装/清洁提示、服务保障条。保持版式高级、留白合理、文字清晰可读。
```

### 如果材质不真实

```Plain Text
请重新按原图校准材质表现：木纹、布纹、皮纹、岩板纹、金属反光、玻璃边缘、软包缝线、藤编纹理等必须与原图一致。不要把一种材质改成另一种材质，不要过度磨皮或过度反光，保留家具真实商业质感。
```

### 如果文字乱码或排版混乱

```Plain Text
请重做文字排版，所有中文必须清晰、规范、可读。主标题 6 到 14 个字，副标题 10 到 24 个字，卖点短句 3 到 5 条，每条 4 到 10 个字。文字需要按品牌条、主标题、副标题、卖点标签、参数卡、底部信息条分层排版，不要出现乱码、错别字、英文伪字或无意义装饰字。
```

## 最终验收标准

1. 产品外观一致：品类、结构、比例、颜色、材质、关键细节没有跑偏。

2. 页面职责清晰：8 页之间不是简单换背景，每页都承担不同转化任务。

3. 信息真实合规：没有编造尺寸、承重、环保等级、材质等级、销量和认证。

4. 家具感明确：有空间尺度、材质细节、结构说明、风格搭配和生活方式。

5. 电商感足够：有标题、卖点、标签、参数、信任条和购买理由。

6. 文字可读：中文清晰，层级明确，不卡边，不遮挡产品。

7. 可直接交付：单页可独立用于详情页，整套可拼成长图。
