# 海产品类主图与详情页生图提示词 SOP

## 适用品类说明

这份 SOP 用于把 `1 张海产品图` 或 `多张同一海产品不同视角图`，转成一整套可直接交给生图工具执行的电商主图和详情页中文生图提示词。

适合：

1. 鲜活海产品：虾、蟹、贝类、鱼类、海参、鲍鱼等。

2. 冷冻海产品：冻虾、冻鱼片、冻蟹、冻扇贝、冻鱿鱼、冻海鲜组合等。

3. 海产干货：干贝、虾皮、海米、鱼干、鱿鱼干、海带、紫菜、干海参等。

4. 预制/即食海产品：调味小海鲜、即食海参、熟冻海鲜、海鲜礼盒、半成品海鲜菜等。

5. 以包装销售为主的海产品、海鲜礼盒、冷链生鲜套餐。

不适合：

1. 同时上传多个不同产品，却没有说明主推款。

2. 想让 AI 自动编写产地、等级、检测报告、净含量、保质期、物流时效、捕捞方式、养殖方式等真实资料。

3. 产品图严重模糊、包装文字看不清、主体被遮挡、无法判断是鲜活、冷冻、干货还是熟制。

4. 需要生成具体食品安全承诺、医疗保健功效、夸张营养功效，但没有真实依据。

## 核心原则

1. 产品外观必须保真：不改品类、不改颜色、不改大小比例、不改包装、不改形态、不乱加配料。

2. 海产品类型必须分清：鲜活、冷冻、干货、熟制、即食、礼盒不能互相混淆。

3. 信息必须保守：产地、野生/养殖、捕捞方式、等级、净含量、规格、检测、认证、保质期、冷链时效、价格、销量不能凭空编造。

4. 视觉必须有食欲和新鲜感，但不能把普通海产品做成夸张“刺身级”“医养滋补”“顶级进口”等无依据表达。

5. 主图负责点击和识别，详情页负责解释和转化；每张图的职责要不同，不要只是换背景。

6. 所有生成结果都要能继续返修：产品跑品、文案虚构、文字乱码、场景不匹配时，必须有明确修正路径。

## 使用前准备

推荐准备：

1. 产品主体清晰的图片，最好包含正面、侧面、包装、开箱、局部细节。

2. 如果是冷冻品，尽量提供包装正面、产品裸露状态、冻品纹理或实物盘装图。

3. 如果是干货，尽量提供近景质地、颗粒大小、包装标签。

4. 如果是鲜活产品，尽量提供真实鲜活状态、规格参考、发货包装或养殖/暂养环境图。

5. 如果是礼盒，尽量提供外盒、内托、单品摆放、套餐明细。

6. 真实资料建议提前整理：产品名称、品牌名、规格、净含量、产地、储存方式、食用方式、发货方式、保质期、适用场景、平台。

### 默认值规则

如果用户输入区没有填写，按以下默认逻辑执行：

1. `平台`：默认按淘宝 / 天猫 / 抖音电商转化逻辑生成。

2. `输出语言`：默认中文。

3. `主图数量`：根据产品复杂度、卖点数量、可见信息量自动生成。

4. `详情页数量`：根据购买决策链路、信息复杂度和转化需要自动生成。

5. `主图比例`：默认 `1:1` 方图。

6. `详情页比例`：默认 `3:4` 竖版单页，可后续拼成长图。

7. `海产品类型`：未填写时根据图片判断；无法判断时使用“待确认海产品类型位”。

8. `品牌名`：未填写时使用“品牌占位”，不强行虚构品牌。

9. `真实规格 / 净含量 / 产地 / 储存方式 / 发货方式 / 食用方式`：未填写时只能使用占位符，不能编造。

10. `核心卖点`：未填写时根据图片可见特征和品类常见购买理由保守生成。

11. `设计风格`：未填写时根据产品类型自动生成，例如冰鲜冷链感、海洋清爽感、干货质朴感、礼盒高端感、家庭餐桌感。

## 标准工作流

### 第一步：产品识别与风险判断

先把产品图发给 Gemini / 豆包，用下面提示词让 AI 识别产品事实，不要急着生图。

```Plain Text
你是一名海产品电商视觉策划和 AI 生图提示词导演。请根据我上传的产品图，先整理一份海产品基础识别报告。

要求：
1. 只基于图片可见信息和我补充的信息判断，不确定的内容写“无法从图中确认”，不要编造。
2. 判断产品属于鲜活、冷冻、干货、熟制、即食、半成品、礼盒中的哪一类；如果无法判断，请写“待确认海产品类型位”。
3. 识别产品品类、外观形态、颜色、质地、包装、标签、可见文字、数量关系、是否有冰鲜/冷冻/干货/熟制特征。
4. 列出可确认信息、无法确认信息、不能用于图内文案的信息。
5. 提炼 3-5 个可用于电商表达的保守卖点，每个卖点写成“卖点名称 + 用户利益 + 适合怎么视觉化”。
6. 列出后续生图最容易出错的风险点，例如把冷冻品画成活鲜、把干货画成鲜活、乱写产地、乱写净重、乱写检测认证、文字乱码、产品跑品等。
7. 最后输出一段“产品外观锁定描述”，后续所有主图和详情页提示词都要复用。

请按以下结构输出：
- 产品基础画像
- 海产品类型判断
- 可确认信息
- 无法确认的信息
- 禁止编造的信息
- 核心卖点
- 生图风险点
- 产品外观锁定描述
```

### 第二步：可选精修成干净产品底图

如果原图背景杂乱、光线差、边缘不清，先用下面提示词精修底图。

```Plain Text
请把我上传的海产品图片精修成适合后续电商主图和详情页生图参考的干净产品底图。

要求：
1. 严格保持产品真实品类、外观形态、数量关系、大小比例、颜色、质地、包装、Logo、标签和可见细节不变。
2. 如果是鲜活海产品，保持真实鲜活状态和自然水润质感，不要改成冷冻品或熟制品。
3. 如果是冷冻海产品，保持冷冻包装、冰衣、冷链感和真实产品形态，不要改成鲜活游动状态。
4. 如果是干货，保持干燥纹理、颜色深浅、颗粒大小、包装关系，不要加水汽、冰块或鲜活场景。
5. 如果是熟制/即食海产品，保持熟制色泽和包装逻辑，不要改成生鲜或刺身状态。
6. 背景处理为干净纯白、浅灰白、浅冷灰或极简中性底色，去除杂物、水印、脏污、过曝和无关道具。
7. 不要新增原图没有的配料、蘸料、餐具、礼盒、冰块、检测标识、产地标识、品牌元素或功能文字。
8. 输出主体完整、边缘清晰、光影自然、真实可信、适合继续用于电商生图参考的产品底图。
```

4. 不得把冷冻品画成鲜活品，不得把干货画成水润鲜品，不得把熟制品画成生鲜品，不得把普通海产品画成刺身级产品。

二、信息真实性规则
1. 只能使用图片可确认信息、用户明确填写信息和高置信度品类推断。
2. 产地、野生/养殖、进口、捕捞方式、等级、净含量、规格、检测认证、冷链时效、保质期、价格、销量、发货范围、售后承诺，未填写时严禁编造。

4. 禁止夸张保健功效、医疗功效、绝对化承诺和无依据高端背书。

三、详情页设计规则
1. 详情页默认适配竖版单页，比例按用户输入读取；未填写时默认 3:4，后续可拼成长图。
2. 每页必须像成熟品牌商详设计稿，不要做成单张简单海报。
3. 每页至少形成 3-5 个信息区块，例如主标题、副标题、卖点标签、规格卡、储存卡、发货卡、食用卡、场景卡、底部信息条。
4. 页面必须有独立价值，不要为了凑页数重复“新鲜、好吃、品质好”。
5. 可根据产品特性自由规划：首屏价值页、产品真实展示页、冷链/储存页、规格净含量页、产地占位页、食用方式页、场景餐桌页、礼盒组合页、细节质感页、信任收口页。
6. 不适合当前产品的页面不要强行输出，例如没有礼盒就不要做礼盒页，没有真实产地就不要做产地溯源页，没有真实食用步骤就用“食用方式待补充”。

四、海产品视觉规则
1. 鲜活类：清澈水感、湿润光泽、干净养殖/暂养氛围、浅海蓝绿调，但不要脏乱市场感。
2. 冷冻类：冰面、冷雾、低温蓝白光、冷链包装、冰晶质感，但不要把产品完全埋进冰里。
3. 干货类：干燥纹理、质地近景、密封包装、米白/木色/海盐色背景，避免水汽和活鲜场景。
4. 熟制/即食类：餐桌场景、开袋即食、色泽食欲、轻厨房氛围，避免生腥画面。
5. 礼盒类：外盒内托、组合陈列、节日礼赠、家庭餐桌，但必须以真实礼盒图为依据。
6. 整套详情页色彩、字体、信息卡片、图标和光影要统一。

五、文字与排版规则
1. 每页都要写出主标题、副标题、卖点短句和信息模块内容。
2. 主标题建议 6-14 个字，副标题建议 10-24 个字，信息模块建议每条 4-12 个字。
3. 每页都要写清文字位置、版式结构、字体气质、字号层级、对齐方式、颜色关系和留白要求。
4. 中文必须清晰、规范、可读，不要乱码、错别字、英文伪字、无意义装饰字。
5. 参数、产地、净含量、储存方式、发货方式等未确认内容必须用占位符，不要生成具体数字。

六、输出要求
1. 只输出最终可用内容，不要输出分析过程。
2. 先输出“产品外观锁定描述”，再输出“详情页生图提示词”。
3. 每页详情页必须包含“页面关键词”和“中文生图提示词”。

## 海产品类常用页面方向

这些是可选方向，不是固定模板。让 AI 根据产品类型自动选择。

1. 首屏价值页：产品识别、核心卖点、品牌感、冷鲜/干货/即食属性。

2. 产品真实展示页：整体、局部、包装、规格关系。

3. 冷链储存页：适合冷冻/鲜活类，但必须有真实发货或储存信息。

4. 口感氛围页：适合熟制、即食、预制类，突出餐桌和食欲感。

5. 干货质地页：适合干贝、虾皮、海米、鱼干、海带、紫菜等。

6. 规格净含量页：必须使用真实信息或占位符。

7. 食用方式页：清蒸、煎烤、煲汤、凉拌、开袋即食等，必须与产品类型匹配。

8. 礼盒组合页：只适合真实礼盒或套餐。

9. 场景人群页：家庭餐桌、节日送礼、露营烧烤、轻食厨房、宴客聚餐等。

10. 信任收口页：保守表达品质、包装、发货、储存提醒，不编认证和检测。

## 质检验收清单

每次出图后按下面清单验收。

### 产品保真

1. 海产品品类是否没变。

2. 鲜活、冷冻、干货、熟制、即食、礼盒属性是否没混淆。

3. 产品形态、数量关系、颜色、质地、包装、Logo、标签是否没跑。

4. 有没有新增原图没有的配料、蘸料、餐具、礼盒、冰块、品牌标识或检测章。

5. 产品主体是否清晰，是否被冰块、道具、文字遮挡。

### 信息真实性

1. 是否乱写产地、野生/养殖、进口、捕捞方式、等级。

2. 是否乱写净含量、规格、保质期、储存方式、发货时效。

3. 是否乱写检测认证、溯源码、销量、价格、售后承诺。

4. 是否出现夸张绝对化词或保健医疗功效。

5. 不确定信息是否使用占位符。

### 视觉转化

1. 主图是否一眼知道卖什么。

2. 产品主体是否足够大、足够清晰。

3. 画面是否干净、有食欲、有类目质感。

4. 文字是否清楚可读，没有乱码和错别字。

5. 每张主图和每页详情页职责是否不同。

6. 整套视觉是否统一，不像临时拼图。
