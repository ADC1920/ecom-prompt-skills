# 3C数码类主图与详情页生图 SOP

## 适用品类说明

适合：

1. 蓝牙耳机、音箱、充电器、数据线、充电宝

2. 鼠标、键盘、U 盘、读卡器、硬盘盒

3. 小型数码配件、桌面数码、便携电子产品

4. 外观和功能都偏“科技感、参数感、连接感”的 3C 标品

不太适合：

1. 大家电

2. 强家居装饰属性产品

3. 纯服饰、纯食品、纯美妆类

## 使用前准备

推荐准备：

1. 主体完整、角度清晰、尽量干净的产品实拍图，最好是3张不同视角的。

2. 最好是白底图；如果不是，也可以先让 AI 精修成白底图

3. 如果能补充品牌名、核心卖点、价格带，效果会更稳；不补也能直接跑

## 第一步：实拍图转白底

把产品实拍图发给 AI，并附上下面这段提示词：

```Plain Text
请帮我仔细精修出产品的白底图，希望能保持它原本的样子，不要做出任何外观上的改变，在展示产品的时候，能呈现出最清晰、最完美的视觉效果。背景处理为干净纯白或极浅灰白，无杂物、无水印、无多余道具，保留产品真实轮廓、比例、材质、颜色和细节结构，适合后续继续用于电商主图和详情页生图参考。
```

## 第二步：Gemini 直出 3C 数码类主图整套生图提示词

### 作用

通过 `1` 张 3C 数码产品白底图 + 下方提示词，让 Gemini 一次性输出：

1. `6` 张标准主图中文生图提示词

2. `2` 张可选增强主图中文生图提示词

### 提示词

```Plain Text
你是一名拥有千万级 GMV 视觉操盘经验的顶级电商视觉总监、商业平面设计师、3C 数码主图策略专家。你尤其擅长把一张 3C 数码产品图片，拆解成一整套适配国内电商平台的主图中文生图提示词。

我只会上传 1 张 3C 数码产品实拍图，除图片外，可能不会再补充任何信息。请你不要反问，直接基于图片完成任务。

你的任务不是做 1 张海报，而是做 1 套 3C 数码主图系统。

请在后台静默完成以下动作，不要输出分析过程：
1. 识别产品属于哪种 3C 数码子类，例如耳机、音箱、充电器、数据线、U 盘、键盘、鼠标、存储设备、桌面数码、小型电子配件。
2. 提炼一段“产品外观锁定描述”，确保后续所有主图都不跑品。
3. 提炼适合主图表达的核心转化信息，例如外观设计、连接能力、兼容关系、使用场景、功能表现、参数感、品质感。
4. 输出 6 张标准主图 + 2 张可选增强主图的中文生图提示词。

请严格遵守以下规则：

一、产品锁定规则
1. 每一张主图提示词都必须以“以原始实拍图作为唯一外观参考，严格复刻产品原貌”作为开头约束。
2. 必须严格保持产品品类、轮廓、比例、结构、颜色、材质表现、表面工艺不变。
3. 不得新增原图中不存在的按钮、接口、纹理、发光结构、装饰、部件。
4. 如果图片里能看出开盖、分体、插头、接口、耳套、按钮、灯位、卡扣等信息，只能在可确认范围内延展，不得擅自改款。

二、信息真实性规则
1. 只能基于图片可见信息和高置信度推断输出。
2. 看不清、看不到、无法确认的续航、功率、蓝牙版本、容量、接口规格、协议、认证、芯片型号，严禁编造。
3. 如果必须做参数区，但参数不足，只能使用“待补充参数位”“待补充规格位”“待补充兼容位”，不能伪造具体数字。
4. 卖点优先写成用户利益点，但不能虚构产品做不到的功能。

三、3C 数码视觉规则
1. 主图默认适配国内主流电商平台方图，按 1:1 构图。
2. 整套主图要有统一的科技感和品牌感，但每一张图的职责必须不同。
3. 3C 数码类优先使用科技感、光效、功能界面、设备联动、参数网格、兼容模块、能量流、结构说明等视觉语言。
4. 如果产品本身偏商务极简，就走克制高级路线；如果产品偏电竞、音频、硬核科技，就允许更强对比和更强动势。
5. 不要做成廉价模板图，也不要过度赛博到看不清产品。

四、信息布局规则
1. 每张主图至少包含以下信息层中的 3 个以上：品牌条、主标题区、副标题区、卖点标签区、功能 icon 区、参数/兼容区、角标/徽章区、底部信任条。
2. 主标题建议 6 到 14 个字，副标题建议 10 到 24 个字。
3. 卖点短句建议 3 到 5 条，每条 4 到 10 个字。
4. 主图的信息密度要通过模块化实现，不要靠长段文字。
5. 文字必须和产品、背景、功能模块一起构成完整电商版面。

五、输出规则
1. 只输出“图片标题 + 中文生图提示词”，不要输出解释说明。
2. 每张中文生图提示词都必须是可直接复制给生图工具的完整版本。
3. 每张提示词都必须写清产品锁定、构图、主体位置、背景/场景、光影、标题内容、卖点标签内容、角标内容、底部信息条内容、字体气质、对齐方式、商业质感。
4. 如果图片中没有明确品牌名，统一使用“自定义”作为默认品牌名。
5. 不要输出英文版提示词。

请按以下结构输出：

## 主图 1：爆点首图 / 品牌主海报
中文生图提示词：
这一张必须是整套主图里最强视觉冲击的一张。必须包含大比例产品主体、强主标题、副标题、品牌条、角标、底部功能或信任条。适合突出外观设计、科技气质或最强卖点。

## 主图 2：核心卖点图
中文生图提示词：
这一张必须讲清 3 到 4 个核心卖点。优先使用产品主体 + 卖点模块 + icon 标签的结构。适合突出降噪、续航、充电、连接、便携、音质、手感、稳定性等利益点，但如果信息无法确认，要保守表达。

## 主图 3：场景氛围图
中文生图提示词：
这一张必须建立 3C 产品的使用语境。可以是通勤、桌面办公、游戏娱乐、出行、学习、移动设备搭配等场景。必须有产品主体、场景关系、主标题、场景说明和场景标签。

## 主图 4：功能演示图
中文生图提示词：
这一张必须把 1 个核心功能做得更可感知。可以加入界面、设备联动画面、声波/能量流、连接可视化、数据感模块，但要让用户一眼看懂，不要只做炫技背景。

## 主图 5：细节 / 参数 / 兼容图
中文生图提示词：
这一张必须偏理性说明。优先展示结构细节、接口、仓体关系、材质工艺、兼容设备、参数信息块、连接模块。页面排版要更规整，更像说明型电商图。

## 主图 6：信任 / 促销收口图
中文生图提示词：
这一张必须承担最后收口作用。必须有产品标准展示、总结型标题、购买理由标签、服务/信任/活动模块。如果价格和活动未知，使用“新品上市”“官方甄选”“热卖推荐”“限时加赠”这类保守表达。

## 可选主图 7：对比图
中文生图提示词：
如果该产品适合做对比，请生成对比型主图；若不适合直接对比，就改成“优势总结增强图”。必须有清晰对比结构、结论型标题、正反标签或优势标签。

## 可选主图 8：设备联动 / 套装增强图
中文生图提示词：
如果该产品适合做设备联动、配件组合、多场景搭配，请生成增强型主图；若不适合，就改成“补充购买理由增强图”。必须有产品主体、扩展说明模块、补刀型标题和更强的后半程转化逻辑。
```

## 第四步：把白底图 + 提示词喂给生图工具

操作方式：

1. 把 Gemini 输出的每一页“中文生图提示词”复制出来

2. 再把产品白底图和对应提示词一起发给批量生图工具 musart ai / 稿定ai / 星流 / lovart，选择 nano banana 2 或 nano banana pro 模型，输出质量：nano banana pro 优于 nano banana 2

3. 主图按 `1:1` 生成，也有电商平台主图是支持`3:4`的，详情页按 `3:4` 生成

4. 如果某页第一次效果不稳，优先补“补刀提示词”，不要急着重写整套

## 这个类目最容易翻车的点

1. 把 3C 数码做得太赛博，导致产品本身看不清

2. 自行编造蓝牙版本、续航、功率、容量、协议、认证

3. UI 和参数模块很酷，但和产品真实功能脱节

4. 为了科技感新增灯效、接口、按键，导致跑品

5. 文字很多，但没有模块层级，看起来像大段说明书

## 类目专用补刀说明

### 如果主图不够像 3C

```Plain Text
请把整套主图的视觉语言再往 3C 数码方向加强：增加更明确的功能 icon、参数感模块、设备联动关系、理性科技排版和更克制的金属/玻璃/磨砂材质描述，但必须保持产品原貌，不要新增不存在的结构。
```

### 如果详情页信息密度不够

```Plain Text
请把每一页详情页的版式信息密度再提高，不是增加长文案，而是增加模块化信息区块，例如参数卡、兼容模块、图标栏、引导线说明、编号标签、底部信息条，让页面更像成熟品牌的 3C 商详设计稿。
```

### 如果产品开始跑品

```Plain Text
请重新强化产品锁定规则：以原始实拍图作为唯一外观参考，严格保持品类、轮廓、比例、接口、按钮、结构、颜色和材质表现不变，不得新增任何原图中不存在的结构和细节。
```
