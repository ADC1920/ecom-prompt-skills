# 百货杯壶类主图与详情页生图 SOP

## 适用品类说明

适合：

1. 保温杯、水杯、水壶、饭盒、便携餐盒

2. 杯壶收纳类、通勤餐饮类、居家百货类

3. 以及相近的生活百货标品，例如小型桌面计时器、轻收纳用品、便携生活器具

不太适合：

1. 强 3C 数码产品

2. 强美妆护肤产品

3. 纯包装食品

## 使用前准备

推荐准备：

1. 主体完整、开合结构或容量关系尽量看得清的产品图，最好是3张不同视角的。

2. 如果是杯壶饭盒类，尽量让盖子、把手、分层、容量轮廓清晰

3. 若能补充品牌名、容量、材质、保温时长、使用场景会更稳；不补也能先跑保守版

## 第一步：实拍图转白底

把产品实拍图发给 AI，并附上下面这段提示词：

```Plain Text
请帮我仔细精修出产品的白底图，希望能保持它原本的样子，不要做出任何外观上的改变，在展示产品的时候，能呈现出最清晰、最完美的视觉效果。背景处理为干净纯白或极浅暖灰，不要加入多余道具，不要改变产品颜色、盖子结构、把手、分层、按键、开口、材质和比例，适合后续继续用于百货杯壶类主图和详情页生图参考。
```

1. 每一张主图提示词都必须以“以原始实拍图作为唯一外观参考，严格复刻产品原貌”作为开头约束。

1. 只能基于图片可见信息和高置信度推断输出。
2. 看不清、看不到、无法确认的容量、保温时长、密封性能、材质层数、食品级认证、使用温度，严禁编造。
3. 如果必须做参数区，但信息不足，只能使用“待补充参数位”“待补充容量位”“待补充材质位”。
4. 卖点优先写成用户利益点，但不能把普通百货写成夸张黑科技。

三、百货杯壶类视觉规则
1. 主图默认适配国内主流电商平台方图，按 1:1 构图。
2. 整套主图优先走生活方式、桌面场景、通勤场景、居家温暖感、材质清爽感。
3. 如果产品偏饭盒餐盒，可以加入餐桌、办公桌、书桌、便携餐食、容量感语言。
4. 如果产品偏杯壶保温杯，可以加入通勤、办公、书包、桌面、车载、户外轻场景语言。
5. 不要堆太多杂物，道具只是辅助，不要盖过产品主体。

四、信息布局规则
1. 每张主图至少包含以下信息层中的 3 个以上：品牌条、主标题区、副标题区、卖点标签区、容量/结构/材质小模块、角标/徽章区、底部信任条。
2. 主标题建议 6 到 14 个字，副标题建议 10 到 24 个字。
3. 卖点短句建议 3 到 5 条，每条 4 到 10 个字。
4. 主图信息要清楚、温暖、实用，不要只有氛围没有电商效率。
5. 文字必须与产品、场景和模块结构一起组成完整版面。

五、输出规则
1. 只输出“图片标题 + 中文生图提示词”，不要输出解释说明。
2. 每张中文生图提示词都必须是可直接复制给生图工具的完整版本。
3. 每张提示词都必须写清产品锁定、构图、主体位置、背景/场景、光影、标题内容、卖点标签内容、角标内容、底部信息条内容、字体气质、对齐方式和整体商业质感。
4. 如果图片中没有明确品牌名，统一使用“自定义”作为默认品牌名。
5. 不要输出英文版提示词。

请按以下结构输出：

## 主图 1：爆点首图 / 品牌主海报
中文生图提示词：

## 主图 2：核心卖点图
中文生图提示词：
这一张必须讲清 3 到 4 个核心卖点。适合突出容量感、材质感、收纳关系、便携感、桌面适配、开合结构、分层逻辑、好清洁感。

## 主图 3：场景氛围图
中文生图提示词：
这一张必须建立办公、通勤、居家、书桌、厨房、餐桌、校园、车载等场景。必须有产品主体、场景说明和场景标签。

## 主图 4：功能演示图
中文生图提示词：
这一张必须把 1 个核心使用点做得更具体，例如开合、收纳、便携、分层、容量、摆放、桌面关系、外带关系。要让用户一眼看懂使用逻辑。

## 主图 5：细节 / 参数 / 容量图
中文生图提示词：
这一张必须偏理性说明。适合放结构细节、材质细节、开口细节、杯盖细节、容量块、尺寸块、适用场景块。

## 主图 6：信任 / 促销收口图
中文生图提示词：
这一张必须承担最后收口作用。必须有产品标准展示、总结型标题、购买理由标签、服务/活动/信任模块。如果价格和活动未知，使用保守表达。

## 可选主图 7：对比图
中文生图提示词：
如果该产品适合做对比，请生成对比型主图；若不适合，就改成“优势总结增强图”。适合做容量对比、场景对比、结构对比、使用便利对比。

## 第四步：把白底图 + 提示词喂给生图工具

操作方式：

1. 把 Gemini 输出的每一页“中文生图提示词”复制出来

2. 再把产品白底图和对应提示词一起发给批量生图工具 musart ai / 稿定ai / 星流 / lovart，选择 nano banana 2 或 nano banana pro 模型，输出质量：nano banana pro 优于 nano banana 2

3. 主图按 `1:1` 生成也有电商平台主图是支持`3:4`的，详情页按 `3:4` 生成

4. 某一页不稳时，优先用补刀提示词微调

## 这个类目最容易翻车的点

1. 擅自把容量、保温时长、密封性写成具体数字

2. 为了生活方式感放太多道具，导致产品主体不突出

3. 开口、杯盖、把手、提手、分层关系被改掉

4. 整套图只有暖光氛围，没有电商信息布局

5. 把普通百货做成科技风或美妆风，类目气质跑偏

## 类目专用补刀说明

### 如果主图不够像生活百货

```Plain Text
请把整套主图的视觉气质再往生活方式百货方向加强：增加桌面感、通勤感、居家感、材质感、容量或结构模块，但不要增加无关杂物，必须保持产品仍然是一眼主角。
```

### 如果详情页信息不够实用

```Plain Text
请把每一页详情页的实用信息密度再提高：增加容量区、结构说明区、使用场景区、材质区、清洗或收纳说明区，让页面更像成熟的生活百货商详，而不是只有氛围的展示图。
```

### 如果产品开始跑品

```Plain Text
请重新强化产品锁定规则：以原始实拍图作为唯一外观参考，严格保持产品轮廓、颜色、材质、盖子、把手、分层、开口和结构关系不变，不得新增任何原图中不存在的结构。
```
